# Agent Note: WorldAxis V3 双九项规划（优化提升 OPV3 + 拓展创新 EXV3）

Status: rejected — 已被 V4 规划取代：V3 主题能力在后续产品提交中大面积落地，旧待办会造成重复建设。

## Problem

用户要求基于当前仓库现状为 WorldAxis 制定两个各九项的完整计划（共十八项）：一份优化提升，一份拓展、拓宽与创新。
核心约束与背景：
1. **立足现状、摒弃过时信息**：仓库元数据已达 `2.231.6`（基线 `8ab817b`），此前的 WP/WX 双九项及 A/B/C 三大更新包已在上一轮完成并合入 master。不能把历史计划中的“未实施”直接当作当前缺口。
2. **警惕守卫/审计挤占功能开发**：现有项目已有约 235 个产品 JS 文件、约 100 个世界引擎、23 页面板，守卫体系已近完备。若继续以新增守卫、审计或页面为核心，将严重偏离世界系统的主题本身。
3. **拒绝重复套路，打造差异化独有机制**：坚决不再追加师徒系统、纯数值成长或无休止的平行实体。优化线必须围绕“有限时间、有限资源、有限认知、可追溯承诺”打通玩家可感知的行动—代价—后果闭环；拓展线必须体现“承载压力、公共选择、有限传播、地方实践和历史解释中产生路径依赖”的独有机制。
4. **工作量饱满**：计划量必须足够大，至少能支撑三天以上（本规划实际估算 478–758 有效工程小时，包含大批次渐进演进）的实质产品功能开发。

## Proposal

在 `plans/` 下新增两份 V3 规格计划，并在 `NEXT_PLAN.md` 顶部提供唯一最新规划入口：
- [WORLDAXIS_OPTIMIZATION_9_V3.md](../../../../plans/WORLDAXIS_OPTIMIZATION_9_V3.md)：优化提升 OPV3-1～OPV3-9，估算 222–352 小时。涵盖世界情境投影、完整行动桌、单一剧情时间、能力物件结果链、知识驱动角色行动、承诺与履约回路、后果到行动空间、场景回声与历史追溯、主题化新局。
- [WORLDAXIS_EXPANSION_9_V3.md](../../../../plans/WORLDAXIS_EXPANSION_9_V3.md)：拓展创新 EXV3-1～EXV3-9，估算 256–406 小时。涵盖承载力与资源回生、公共服务网络、有限注意与传播、共同资源与协作失败、惯例形成与地方规则、地方实践与兼容分化、群体解释与历史争议、连锁冲击与恢复路径、地方路径与时代转折。

两线合计 18 项，逐项相加估算 478–758 有效工程小时，明确划分三大更新批次与前三个有效工作日的功能切片，不以守卫或测试项替代产品功能。

## Decision

采纳 V3 双九项规划作为当前工作纲领。坚持：
1. 不新建第二份人物、库存、时间、事实或关系真源。
2. 不以新增引擎数、守卫数或面板页数衡量进展。
3. 守卫、测试与审计只作为验收手段，不单独占用产品功能名额。
4. 所有功能必须具备端到端纵向链：“正常入口 → 真实 owner 结算 → 可见后果 → 保存重载 → 下一场景消费”。

## Consequences

- 研发重心完全回归核心机制与剧情体验，避免了元工作空转。
- 每项功能必须面对现有复杂引擎的真实接口，工程集成深度提高。
- 面板不再为每个内部引擎新增页面，而是向统一的情境投影、行动桌和场景叙事收束。

## Alternatives considered

- **继续在 WP/WX 上追加小补丁**：不可取，WP/WX 规划的既定目标已在 `8ab817b` 全部闭环，强行延长旧计划会掩盖新层面的核心诉求。
- **只做守卫和性能治理**：违背用户明确指令，守卫不能成为第二系统。
- **设计虚构的师徒/修仙养成数值**：偏离 WorldAxis 严肃沙盒与社会演化的独特机制定位。

## Acceptance criteria

1. 优化计划 OPV3-1～9 与拓展计划 EXV3-1～9 均为严格 9 项，共 18 项。
2. 每项均包含明确的真实缺口/问题、交付内容、结项下限、优先级与工时估算。
3. `NEXT_PLAN.md` 完成同步更新，历史计划保留为追溯存档。
4. 本次规划变更合规提交并推送至远端 GitHub 仓库。
