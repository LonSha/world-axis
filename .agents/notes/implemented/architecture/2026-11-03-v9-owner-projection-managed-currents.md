# Agent Note: V9 owner 正文投影与显式暗流托管

Status: implemented

## Problem
家庭、研究、机会、拍账已有写口及作者读口，但没有直接正文注入分支。把这些块接入通用正文后，原先仅在作者面可见的研究假设与目标成果也会进入模型上下文；一句“不得全知”不能替代内容隔离。暗流日历的 ETA 是估算，不是已登记期限，不能据此改变世界阶段。静态 grep 又漏掉 SC/CM/IV/AF/OP 别名，误报了已有启用开关。

## Decision
四个 owner 的源表、缺省可见性、中文名、模块设置键、正文分支与面板显示名同批登记。owner 总开关保留默认关闭，不向 collector 再灌一份全文。拍账只列已落及当前拍；机会优先活跃窗口，最多附两条已错过历史且明确不可参与。家庭只投影真实余额、照护交接及财产交接，不编期限。
研究通用块没有可信查看人，secret/transferred 只显示脱敏进度，假设、材料、目标和成果细节留在作者 view/list；只有 public 项目展示详细成果，确认前不当成结果。这样牺牲私密研究在普通正文中的细节，但不把私有材料扩散给模型后再要求它自律。
暗流阶段写口仍由 backstage 持有。storylineAdvance 默认关，通过成功推演事务后的调用点请求 owner 推进；玩家还必须在世界页逐条显式托管五段暗流。按真实 evolution 轮号及配置的每阶段轮数推进，一次最多一段，同轮重答、回退轮号和终段不再推进。日历 ETA 从不转成事实截止日；推演显式改变阶段后重置托管基准，避免同轮二次加速。原文 summary 不改，推进证据只在该条 current 上保存一条 advanceLast，不建无界日志。hidden/trace 的标题及内容不进入新正文源。
原有十五段折叠保留 page:sec 格式及惰性函数体。设置五卡已有开关，只补真实容量数值写回。检索明确限定当前页已展开设置，过滤标签和高亮，不触发设置写入，不为了全局检索强制构建隐藏页。预算看板复用 lastInjection.volume 和 budget 实际快照，显示共享池，不虚构每源额度。

## Alternatives considered
- 把四 owner 全文并入 collector：只有一处汇流出口，但会重复既有正文材料并模糊各 owner 开关归属；采用直接源。
- 私密研究全量输出并加认知免责声明：叙事细节更足，但模型已获得秘密，声明不能阻止泄漏；采用字段脱敏。
- 日历估算倒计时自动推进所有暗流：无需玩家配置，但把风险预测当成事实，且与推演写口竞争；采用默认关闭、逐条托管、真实轮号、owner 单写口。
- 新建折叠键格式和五卡启用开关：字面扫描容易实现，但原结构没有缺陷，开关也已存在；保留兼容格式，扩展真实容量控件。
- 全页同时构建以搜索所有设置：搜索覆盖广，但破坏折叠惰性与首屏成本边界；当前页搜索显式标注范围，未宣称全局覆盖。

## Consequences
新增材料能通过宿主 setExtensionPrompt 落地，单 owner 故障不拖垮其他源。applyInjections 会写 lastInjection 并使 meta 的 updatedAt/stateRev/writer/writeSeq 增长，所以只读验证逐字段排除这些已知诊断写，不剔除其他世界字段。输入 ctx.injections 是上游候选而非输出数组，专项必须截获实际宿主写入。
托管只改变阶段，不创造解决事件，不自动删终段，不保证叙事结果已经发生。推进模块默认关且逐条 opt-in，未托管旧局不变。世界页仍是作者管理面；这里的 Chromium 桩宿主验证不是 SillyTavern 实机验收。
