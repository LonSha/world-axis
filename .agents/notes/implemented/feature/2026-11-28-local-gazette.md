# Agent Note: 地方图志只关联已公开的地点事实

Status: implemented

## Problem

手札和地图从不同入口读取同一世界。暗流原始标题、发行地未明的社论与教团内部戒律并非玩家在某地能知道的事。反复排期还可能使同地候补越过在席议案。

## Decision

地方图志从已登记的公开路线地点出发，在读取时汇总道路、议案、刊论和信仰；不生成坐标，也不写回存档。暗流的 publicPlace 表示迹象出现处，刊论的同名字段表示公开发行地点。教团必须另给 publicTeaching。手札正文和引用共用 playerCurrent 对暗流的可见性判断，完整地图和手札共用图志渲染。

席位从本地已排期及审议中的议案重建。结案释放席位，但候补需经过下一次排期；渲染不会触发排期。

## Alternatives considered

复用暗流日历条目可少写一个投影，但条目可携带原始标题，不是玩家文本。按叙述中的地名自动归类能填充旧存档，却无法区分活动地和公开迹象出现处。两者均不采用。

## Consequences

旧存档无需迁移，未注明地点的材料暂不出现在图志。只看见迹象时没有幕后标题可引用。此契约只涵盖图志与手札暗流引用，不代表其他历史面板已经过同样审计。tests/local-gazette.js 锁定只读、席位交替和保密边界。既有活跃笔记未检出同一契约。
