# Agent Note: 正文推进只结算当前场景的新事实

Status: implemented

## Problem

时长解析能拒绝问句，日历的跳日分支却仍按关键词拨钟。玩家到校与学生在校是两件事，读到一段路的耗时与实际又走了一段路也不是同一件事。

## Decision

时段、跳日、明确时长和结课共用叙事事实过滤。复述上一段已结算的玩家行程时，按起终点和耗时核对；新行动不会仅因分钟数相同而被排除。课程匹配检查明确地点和主语的已知行程；不从正文反写人物位置。

## Alternatives considered

只看玩家位置可以兼容缺地图的卡，但不能否决已经登记的异地或在途证据。要求每位学生都有到场记录则会破坏原有的无行程教学场景，因此保留明确完成措辞且没有相反位置证据的旧口径。

## Consequences

宁可不结算含混语句，也不从同名日程猜结束时刻。短句规则不代替完整的自然语言分析；同楼层同一时长去重不是重写或删除楼层后的全状态回滚。运行 tests/action-duration-clock.js 验证正常耗时、复述、地点矛盾和到校后的真实完成。
