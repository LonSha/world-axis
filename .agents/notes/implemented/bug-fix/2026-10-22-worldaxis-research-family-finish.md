# Agent Note: 研究耗料、制造权限与共同生活资产交接修复

Status: implemented

> **后续范围（2026-10-24）**：[WP/WX 玩法增量规划](../../proposed/architecture/2026-10-24-worldaxis-play-depth-emergence.md)承接本文未覆盖的正常入口与持续履约，不重复宣称本文修复为新增成果。本文的版本、测试与推送范围保留其历史时点。

## Problem

v2.231.0 的 EXP-8 初版第一阶段不耗料，前置条件只看名称非空，正常 API 无法走到失败；制造方没有消费研究权限。EXP-9 均分资产先截断比例与数量、再清空来源，销毁余量。此前专项还重复执行负控制，78/0、82/0 不能证明功能链成立。

## Decision

研究的 phase 表示已完成且已扣料的阶段数。materials 是项目总量，逐阶段消耗累计目标与 consumed 的差额，最后结清；缺料不推进。前置通过 advance 的 evidence 显式确认，缺少确认时终局失败并保留缺失清单，重试复制线索但不复制进度。当前 evidence 是调用方确认，不冒充自动设备/情报验证。

配方仍由 economy/recipe 定义。economy.craft 与 production.open 消费 research.canUse 的 manufacture 模式：只有启用研究且已有对应 recipe 项目时约束制造；关闭研究或普通配方继续旧行为。同组织取 evolution.factions 的 roster；遍历独立发现，不让第一条成果遮蔽其他授权。

家庭交接要求显式事件，拒绝重复继承人与自继承。均分不预先截断，最后一人取得 remaining，避免凭空销毁资源。资产不包含 knowledge；视图与操作回执不暴露可变内部引用，照护 history 可读。store 默认骨架与部分容量声明一并接通。

## Alternatives considered

- 仅调整原测试的阶段边界最省改动，但会继续掩盖首阶段免费、失败不可达与制造未消费权限，因此重写研究专项，用真实题材配方验证 craft/production。
- 对所有配方一律研究后才能制造最简单，却破坏关闭机制与普通配方的旧语义，因此仅约束显式立项的研究配方。
- 保持定点舍入便于显示，但当前资源并未声明统一最小单位；采用末位接余量，不擅自改变所有资源精度。未来资源粒度仍须按题材定义。

## Testing

仅运行相关专项：exp8-research-v2231 50/0、exp9-family-v2231 83/0、exp3-production-v2231 90/0、opt8-lexicon-v2231 73/0，独立 Node 退出码均为 0。测试覆盖真实制造授权、失败重试、材料/资产守恒、视图隔离、save 后新环境重载。研究三组负控制加载内存中的破坏源码副本重跑同款判据。

按用户指令不运行 tests/run.js 全量回归；真实宿主 UI 未验收。上述结果只证明所列专项，不代表全部 v2.231.0 未提交批次已经验收。

## Consequences

研究成果开始影响实际制造，共同生活交接不再因舍入丢失资产。代价是未完成旧研究项目的 consumed/evidence 兼容仍需有针对性的迁移设计；一般浮点组合、继承自定义比例、事件幂等、责任交接、自动前置验证、研究/家庭面板与叙事消费未在本次完成。生产授权本次检查开单入口，不承诺中途撤权行为。

提交保留此前整轮 v2.231.0 已有修改及其依赖，不覆盖或拆掉前序功能；一次性补丁和 .bak 移至仓库外备份。版本仍为 2.231.0，不因文档补交另造功能版本。
