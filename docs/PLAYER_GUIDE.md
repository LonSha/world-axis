# WorldAxis 玩家说明书

这份文档**只写给装它的人**。里面没有模块名、没有校验脚本、没有内部接口名 ——
那些东西是给改代码的人看的，在 `docs/` 的其它几份里。

---

## 一、装了它会怎样

先说结论：**它不会自动让世界热闹起来**。装好之后你需要做三件事，
做完之后它才开始替你在**你看不见的地方**推演这个世界。

它做的事是：**在你说话之外，世界自己也在动**。
- 你不在场的地方，别人在过日子（谁在哪、做什么、接下来要做什么）；
- 有些事在暗地里推进，过几天会撞上你（你能提前看到还有几轮窗口）；
- 你和某个人的关系会因为具体的事变暖或变冷（它会把「因为什么」列出来）；
- 上面这些都会以一两句人话出现在你面板的概览页上，不用你去翻。

它**不会**做的事：不会替你写剧情、不会自己开新对话、不会把你不该知道的秘密剧透给你。

---

## 二、开哪一档

插件默认是**最省的档位**，一百项机制只跑五项左右。这不是坏了，是刻意的：
省消耗、慢启动。你会看到概览页上写着「只跑了 6 个源（共 107 个）」。

| 你的情况 | 建议 |
|---|---|
| 刚装上，想先看看它长什么样 | 留在默认（轻） |
| 想要世界真的转起来 | 设置页顶部切到**标准**（一次多开一批机制） |
| 想全开（消耗最大） | 切到**完整** |

切换不会删除任何东西，随时可以切回去。切完请**回概览页看一眼**：
那一行会告诉你现在有几个源在出内容 —— 这是唯一可信的判断依据。

## 三、坏了怎么办

按「症状 → 先看哪」的顺序，不按模块查。

| 症状 | 十有八九是 | 怎么办 |
|---|---|---|
| 世界里什么内容都没有 | 三步没做完（最常见的就是 API 没配） | 看概览页顶部的**开局引导**，它会把还差哪一步指出来，点「去做」直接带你去 |
| 面板上写着「读不全」「测不到」 | 某个读数开关关着，**不是**出错 | 那些话的意思就是「这一格没查」，设置页里有对应开关；查了之后那行会自己变 |
| 注入量一直很小 | 引擎开着但源默认关着 | 看概览页的「预算余量」那一行，它会说还能再开几个源 |
| 觉得它在变慢 | 可能真的在变慢 | 概览页的「性能趋势」会告诉你有没有源在劣化（只看斜率，不猜） |
| 说了一句但它没反应 | API 配了但通不了 | 插件看不到宿主的网络层，这一格它不会替你猜；先确认别的对话能正常生成 |

**一句通用话**：这个插件的所有读数都是**现场算出来的**，不是抄来的。
所以「它说没有」通常是「真的没有」，而不是「坏了」。

## 四、几个会被误读的词

这几句话在面板上出现时，它们各自是什么意思：

- **「读不到」/「测不到」/「读不全」**：不是「没有」，也不是「坏了」——
  是**这一项压根没查**（开关关着、或者该模块没装）。它故意不写成 0，
  因为「没量到」和「量出来是零」是两件事。
- **「未结算」**（暗流）：「还没撞上你」。
- **「零引用」**（成本卡）：「这一轮它注入了，但你的正文里一个字没用到它」；
  连续几轮都这样才会被点名。
- **「缺口不等于健康」**：体检单上有几格没读数时，它会这么说。
  意思是「剩下的查过了没事，但没查的那部分我不知道」。
- **「趋势外推，不是精确预言」**：所有涉及「还能跑多久 / 约几轮后」的数字都是这么来的。
  它按你最近的增速画一条直线往前推，**增速一变就不准**。

## 五、你的进度与你的设置

- 「哪一步做完了」这类**装机进度**存在**你自己的浏览器本地**，不进存档。
  所以你把存档导给别人，别人不会看到「你已经配过 API」。
- 世界里的东西（人物、事件、关系）**在存档里**，跟着存档走。
- 两条清空路径（设置页都有）：**「清空进度」**只清装机进度，不碰世界；
  想重置世界要另找世界/存档相关的入口。

---

## 六、隐私（一句话版）

它只跟**你自己配的那个 API 地址**说话，不外发别的地方。
设置的接线、密钥、存档都在你本地。要逐条核对，`docs/privacy.md` 里有。

---

## 七、想看更细的

- 面板上每一块读数都点得开：**诊断**页里是同一批读数的原始形态。
- 想知道「它现在到底在跑什么」：概览页的**能力档位**一行 + **注入预算**一行。
- 想知道某个说法是什么意思：上面第四节的词表；没有的解释，基本都可以在**它自己的读数**里找到，
  因为它只报能当场复算的东西。
