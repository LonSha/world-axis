# 默认值声明面裁决（DFC-1）

> 版本：v2.608.0（R283）
> 锁：`tests/default-face-v2608.js`（24 条判据）
> 复算：`node tests/default-face-v2608.js`

## 一、结论先行

「注释写『总开关默认关闭』而 `const DEF = { enabled: true }`」这件事，**不是一个产品判断，是 127 台引擎共用的一句过期话**。

| 事实 | 数量 | 裁决 | 版本 |
| --- | --- | --- | --- |
| 产品面带 `const DEF = {` 字面量、且能读出 `enabled` 的文件 | 354 | 扫描面（`DEF` 可多行） | — |
| 其中 `settings()` 真用 `DEF` 填默认 | 336 | 判定前提（不用 DEF 就不是矛盾） | — |
| 声明与默认值相反 | 127 | 逐条查证；127/127 命中同一笔提交 | v2.608.0 前 |
| 已关（改的是注释词，不是默认值） | **127** | 零行为影响，101 行→127 行注释 | **v2.608.0** |
| 关闭后现场矛盾 | **0** | 锁进「只减不增」名单 | v2.608.0 |
| 口径外手工校正 4 处 | 4 | 不在扫描面内，但同一句话同样过期 | v2.608.0 |

一句话：**默认值是对的（v2.412.0 的产品决策），注释落后了四个字。**

## 二、它们为什么曾被归成一类（兼一次自纠）

因为判定只需要一句话：*「DEF 上方 80 行的注释里说了『默认关闭』，而 DEF 写的是 `enabled: true`」*。这句话对每一台都完全同形——
不论那台引擎是行为类、数值类、注入类，也不论那句子句在讲什么。

**先说一次自纠。** 本轮第一遍量出的是 **101** 台，口径是「`DEF` 写在单行 + `settings()` 体在一行内」。
改完 101 行之后复扫，`grep` 却另有 **26** 处。原因两个：

1. 有 12 台的 `DEF` 是**多行对象**（`enabled:` 在下一行），第一遍根本没读到；
2. 有十几台的 `settings()` 是多行体 / 箭头写法，第一遍的「同一行内有 DEF」正则认不出。

把口径扩宽（多行 DEF + 「settings() 后 600 字内出现 DEF」）之后：扫描面 271 → **354**、派生 142 → **336**、矛盾 101 → **127**。
这条自纠比结论本身更重要：**「量一遍就量完了」是幻觉，量的动作本身会漏。** 所以锁养了七条两向自证（C1~C7）——
它证的不是「报得对不对」，而是「判据会不会两种情形都看得见」。

更关键的是：**它们长得像「127 个小毛病」，实际是「一次策略变更的余数」**。这是本面与 GNS 面最像的地方——
两边都是「注释在说一件已经不成立的事」，区别只在 GNS 面是**名字**没了，本面是**默认值**翻了。

提交 **35d2c93**（v2.412.0）一次改 205 个文件，`enabled: false` → `enabled: true`：

## 四、逐组：为什么要改的是注释

### 群 A（99 台）：「总开关默认关闭；关闭时 X 报 disabled」

- **源码事实**：`DEF.enabled === true`（现场复算），`settings()` 从 `DEF` 派生。
- **误会在于**：这句子句是两件事拼起来的。后件「关闭时 X 报 `disabled`」**到今天仍然成立**
  ——它描述的是「用户手动关掉之后会怎样」，与出厂默认无关；错的是前三字的**状态**（默认关闭）。
- **改法**：`默认关闭` → `默认开启`。四个字，一处，只动注释行。
- **不改的**：后件一字未动。关掉时的契约比默认值更值钱——它是用户唯一能读到的行为说明。

### 群 B（「开关」未带「总」字等等措辞变体）

例：`engines/request-viewer.js:36`「6 开关默认关闭：关闭时 `capture` 报 `disabled`」。与群 A 同义，同样改成「默认开启」。

### 口径注一：一台引擎可能有两句「默认关闭」

`engines/hazard.js` 里两处：第 24 行「1 总开关默认关闭」（讲本引擎出厂默认）与第 46 行
「总开关 `weatherLink` **默认关闭**」（讲子开关）。锁向上找的是**最近的那条相关声明**，
故判据里多了一句：**「总开关」后面紧跟引号/反引号即视为具名子开关，跳过**（`SUB_RE`，C7 自证）。
没有这一句，锁会指着第 46 行报矛盾——**指向错了比不报更坏**。第 46 行本轮一字未动（子开关确实是默认关的）。

### 口径注二：四条在扫描面外、但同一句话同样过期的

| 位置 | 为何不在扫描面 | 改法 |
| --- | --- | --- |
| `engines/world.js:13` | 它的 `DEF` 是 `__T.DEF`（词表在 `world-tables.js:18`，那里是 `enabled: true`） | 改成「默认开启」 |
| `engines/storyclock.js:106` | 那行在 DEF 之**下**（是函数注释，不是头边界） | 改成「总开关关掉 ⇒ 返回空串」（避开「默认」二字） |
| `engines/gen-timing.js:24 / :44` | 头部另有更近的一条已改；这两处是同一句话的另两个副本 | 分别改成「总开关关着（默认开启）」、「默认开启（v2.412.0 全开策略）」 |
| `engines/ensemble-bridge.js:35`、`calendar-custom-bridge.js:21` | 它们是**引用**这句话作证据，不是声明 | 改成过去时并标注 v2.608.0 |

## 五、改法对照（包括一个「被抄成契约」的后果）

| 方案 | 行为影响 | 代价 | 是否采用 |
| --- | --- | --- | --- |
| 把 `DEF.enabled` 改回 `false` | **真改产品**：127 台引擎出厂不生效 | 撕 v2.412.0 全开策略 | 否（要产品判断） |
| 删掉那句声明 | 零 | 丢掉「关掉后会怎样」的唯一说明，且锁无法再复算 | 否 |
| **把声明改成「默认开启」** | **零**（注释行内四个字） | 127 行 diff | **采用** |

**但有一个后果：** `engines/calendar-custom-bridge.js:61` 早就把这句过期话抄成了一个常量——

```js
/** engines/calendar-custom.js 边界 1 的原文口径：「总开关默认关闭」。 */
const DOC_ENABLED_DEFAULT = false;
```

于是 `switches().contradict` 永远是 `true`。这是本面最深的一层：**过期文档一旦被抄成常量，就成了比文档更硬的错。**
本轮同批：常量改 `true`；`tests/calendar-custom-bridge-v2603.js` 的 C1/C3 从「现场相反」改为「现场同向 + 改一字必报」；
H3 改为「已关的实锤不再配修法」并新增 H3b「造一次相反，修法立刻出现」——**修法列表不是常量，它跟着现场走。**

## 六、门禁这轮做了什么

`tests/default-face-v2608.js`（24 条）：

- **A 扫描面**：产品文件 ≥ 600 / `DEF` 表 ≥ 200 / 派生 ≥ 100 / 与 `product-files.js` 同真源。
- **B 已关闭面（点名 127 台）**：`BASE_CONTRA` 清空 ⇔ 现场 0 条（两向）；**B2 每台的声明行现在写「默认开启」**
  （防「把注释整段删掉」式关门）；**B3 每台 `DEF.enabled` 仍是 `true`**（若翻回 false，这条会把「默认开启」变成新的反话，当场红）；
  B4 声明行仍在 DEF 上方 80 行内；B5 `settings()` 仍用 DEF；B6 名单形态（engines 面、无重复、恰 127 条）。
- **C 七向自证**：合成站点必报（C1）/ 同向不报（C2）/ **反向必报（C3）** / 无 DEF 不报（C4）/ 不用 DEF 不报（C5）/
  正文不算声明（C6）/ 具名子开关不算（C7）。
- **D 零写**：127 台哈希扫描前后一致；不写盘、不起子进程；**D3 裁决文档在位且台数与名单相等**（读 `FIXED.length`，防文档与现场两向漂）。
- **E 读数**：`DEF 面：表 354 · 派生 336 · 矛盾 0 · 已校正 127 · 同向声明 127`。
- **F 口径边界**：窗口 80 行外不认（F1）；只认 `DEF` 里的 `enabled`（F2）；`BASE` 为空且名单无重复（F3）。
