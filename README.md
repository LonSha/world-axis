# 世界枢轴 WorldAxis

> 缝合14个SillyTavern开源世界引擎的**独立扩展**——让镜头之外的世界自行运转并推动剧情。

**纯框架**：不预设任何世界观内容，世界背景由你的角色卡/世界书/用户设定注入。

## 安装
本仓**不发 Release 包**（现场 `git tag` 为 0 —— README 一度把安装第一步写成「去发行页取打包好的 zip」，
那是给人读的那一处与真源脱节，照做在第一步就卡死；已删，并由 `node tools/doc-gate.js --anchors` 钉住）。两条可用路径：
1. **git clone**（推荐，便于更新）：
   `git clone https://github.com/LonSha/world-axis.git SillyTavern/public/scripts/extensions/third-party/WorldAxis`
2. **手动放置**：把仓库解压/复制到 `SillyTavern/public/scripts/extensions/third-party/WorldAxis/`
   （目录名必须是 `WorldAxis`）。
然后：重启酒馆 → 扩展管理启用「世界枢轴 WorldAxis」→ 右下角悬浮球 ◈ 打开面板
→ 「连接」页配置 API 通道（至少配 `default` 或 `inference`）。
> 隐私：世界状态全部落本机 `localStorage`；扩展自身不发任何请求（唯一出站在你自己配的 LLM 通道）。
> 可复算的清单与边界见 [`docs/privacy.md`](docs/privacy.md) 与 `node tools/net-audit.js`。

## 架构
```
before_reply 链:  导演标签扫描 → 连续性约束注入 → 章节上下文 → 突发事件小纸条
                  → NPC独白推演 → 剧情引导拍 → 世界状态快照落地
after_reply 链:   突发事件推进 → 世界推演(backstage) → 事件演化回合
                  → 记忆L0/L1 → 舆情观察 → NPC档案维护 → 对外投影(worldaxis_bridge_v1)
```

## 核心概念
- **世界推演 backstage**：每轮AI回复后，在后台结算镜头外的世界变化（人物位置/暗流/事实/认知边界/世界脉搏），结果写入聊天隔离的store，下一轮以「连续性约束」注入正文。
- **双轴可见性**：事件 visibility(角色能否感知)×publicity(公众传播度)，hidden级暗流绝不剧透给正文。
- **认知边界**：每个NPC独立知识账本，route=inferred 只能标 suspected。
- **世界脉搏**：pressure 0-3 压力账本，驱动世界自发活跃度。
- **记忆分层**：L0单轮摘要→L1阶段巩固→L2章节回顾→L3长线沉淀→facts版本化→伏笔生命周期。
- **事件演化**：冲突/进度双类型四阶段骰子推进（保底机制防卡死）、势力六态七级、声誉四维五级、经济四气候、风声消散、仇敌录、黑盒秘密、天下大势、影响链。
- **远方/近端事件**：Ledger计数阈值强制触发、cooldown冷却、pending重试、临时标记剥离。
- **world_digest**：每轮结算后生成150-200字世界推演叙事，绝对禁止提及玩家。
- **字数限制体系**：events.desc≤50字、factions.currentGoal≤50字、winds.topic≤10字等全字段截断。
- **事件链ID稳定**：API返回id原样使用、改名不换链、type一旦确定禁改、stall停滞标记。

## 工具与体检
- **写入侧完整性**：设置键与存储键全生命周期落盘追踪，写后读回逐字符比对，失败精准三分类并在诊断包透出。
- **删除侧完整性**：统一唯一删除出口，删后读回复核防静默残留，存储健康状态实时动态感知。
- **读侧完整性**：读取失败分桶追踪与来源标记（disk/legacy/default/defaultAfterFailure），防静默回退默认值。
- **出口面清册与契约门禁**：`node tests/inventory.js` 与 `tests/export-contract.js`，全库无悬空引用、零未登记黑盒，接口面变动严格冻结。
- **活性面与死面治理**：存储裸读点全量字面冻结，结构指纹状态机感知，死导出逐级审计与接线闭环。
- **快照导出/恢复**：单文件 JSON 归档，导出剔除运行时脏字段，恢复前格式/schema/字段三重校验，写入前自动留恢复点。
- **世界态势分析器**：本地重算六路压力（事件×等级×阶段进度／风声等级／大势数／势力关系张力／经济气候／区域事件），输出活跃度、上下文负载与风险提示。
- **外部数据导入**：自动判别 6 种格式（全量存档／区域事件单件／势力清单／事件链清单／人物主观记忆／世界书条目组），逐条复用编辑器准入逻辑。

## 编辑器与数据治理
- **势力编辑器**：结构化增删改复制，五要件准入（名称/范围/目标/核心/支柱），重名拒绝（推演按名归并），关系相对位移，声誉总压封顶。
- **事件链编辑器**：阶段序列强校验，跨阶段自动重置阶段轮，正面终局倒计时清退。
- **状态一致性检查器**：纯只读 9 组 checker 覆盖事件/势力/脉搏/人物认知边界/记忆伏笔/来源引用/注入队列/主观记忆/突发事件，返回 error/warn/info 三级结构化报告。

## 构建与验收（当前版本 v2.254.0）

**三档回归**：日常改动跑**快档**（十几秒，覆盖高频核心面），跨文件同值判据与生成物跑**中档**（一分钟级），收口跑**全量**。

```bash
node tools/smoke.js             # 快档：核心契约与高频面（约 10s）
node tools/mid-tier.js          # 中档：快档 ∪ 跨文件一致性面（约 1 分钟）
node tools/net-audit.js         # 网络外呼点位：出站点必须全在白名单内（隐私面，见 docs/privacy.md）
node tests/run.js               # 全量回归入口（收口门槛；整趟约 25-28 分钟）
node tests/inventory.js         # 出口面清册 → 四类悬空均 0
node tests/export-contract.js   # 出口面契约 → ns / members / chars（产物在 .gitignore 内）
```

**读数以现场为准**：本段不写写死的通过/失败计数，全量跑完时 `tests/run.js` 会在末行输出真实读数。
**跑法**：直接 `node tests/run.js` 即可（建议为长局与全量配置 `--max-old-space-size=4096`，外壳硬超时默认值为 2280000ms，慢机可用 `WA_REGRESSION_TIMEOUT_MS` 放宽）。

零依赖：只用 Node 内置模块，无 `package.json`、无 `node_modules`。
每次收口走同一套门禁：出口面契约（逐字冻结）· 死子面账本 · 模块注册与依赖图 · 拒收码归属 · 测试面可达性 · 读数一致性 · 负控制锚点审计 · 生成物一致性 · 网络外呼点位。
逐条说明与读数解释见 [`docs/gates.md`](docs/gates.md)；改代码的规矩见 [`docs/contributing.md`](docs/contributing.md)；分层与单一真源清单见 [`docs/architecture.md`](docs/architecture.md)；拒收码手册见 [`docs/ERROR_CODES.md`](docs/ERROR_CODES.md)；隐私与网络行为见 [`docs/privacy.md`](docs/privacy.md)。
