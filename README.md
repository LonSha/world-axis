# 世界枢轴 WorldAxis

> 给 SillyTavern（酒馆）用的**世界引擎**扩展。
> 它让镜头之外的世界自行运转 —— 你不看的地方，人物在生活、势力在博弈、事件在发酵 ——
> 并把结果自然地推回正文与剧情里。

**纯框架**：不预设任何世界观。世界背景来自你自己的角色卡、世界书与设定。

## 它做什么

装好之后，世界会自己动起来，你能看到也管得着：

- **世界推演** —— 每轮回复之后在后台结算镜头外发生的变化（人物位置、暗流、事实、认知边界），
  下一轮以「连续性约束」注回正文。世界不会因为你没看就停摆。
- **人物** —— 每个 NPC 有自己的档案、知识账本（他知道什么、不知道什么）与独白推演。
  人物只按自己知道的事行动，不会突然全知。
- **事件与势力** —— 冲突与进度按阶段推进，势力、声誉、经济、风声各有自己的账。
  远方的事会自己发酵，也会自己消散。
- **记忆分层** —— 单轮摘要 → 阶段巩固 → 章节回顾 → 长线沉淀，事实版本化，伏笔有生命周期
  （埋了没收会被记成欠账）。
- **剧情工具** —— 拍（叙事节拍）控制、章节工作台、导演视角、剧情参谋与分支推演。
- **世界观照** —— 地图与位置、人物关系图、时间轴、地点痕迹、跨会话的旧事检索。
- **注入与体检** —— 世界状态怎么进正文、进了多少、成本几何，有账可查。
- **存档与搬运** —— 快照导出/导入、分支世界、蓝图互转。

## 界面

面板（右下角悬浮球 ◈）默认只开六个日常页：

**概览 / 世界 / 人物 / 事件 / API / 设置**

其余二十多个机制页（记忆、仇敌、注入、沉积、拍、章节、待办、搬运、检索、图谱……）
收在设置页的「开发者模式」开关里，需要时再打开。

## 安装

本仓不发 Release 包。两条路径任选：

1. **git clone**（推荐，便于更新）：

   ```
   git clone https://github.com/LonSha/world-axis.git SillyTavern/public/scripts/extensions/third-party/WorldAxis
   ```

2. **手动放置**：把仓库复制到
   `SillyTavern/public/scripts/extensions/third-party/WorldAxis/`
   （目录名必须是 `WorldAxis`）。

然后：重启酒馆 → 扩展管理里启用「世界枢轴 WorldAxis」→ 点右下角 ◈ 打开面板
→ 在「连接」页配置 API 通道（至少配 `default` 或 `inference`）。

> **隐私**：世界状态全部存在你本机的 `localStorage`；扩展自身不发任何请求
> （唯一出站是你自己配的 LLM 通道）。
