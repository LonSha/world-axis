## 一句话
玩家打开 ◈，读到的是一本**世界手札**——镜头之外发生了什么，而不是一台诊断控制台。

## 原则
1. **玩家面只回答玩家的问题**：此刻 / 远方 / 人物 / 线索 / 设置，五页。
2. **诊断不进玩家面**：悬浮球角上的小点代替一切「读数」——推演中亮琥珀、失败亮赭红、正常不显示。完整机制页在开发者模式。
3. **一个强调色**：灯火琥珀 #d9a35b。危险用赭红 #b5654a。其余全靠灰阶。
4. **不发光、不玻璃、不渐变**：层次只靠留白与 1px 细线。
5. **衬线讲故事、无衬线讲数据**：标题与引文用宋体，正文与控件用系统无衬线。
6. **统一线性图标**（1.5px 描边），不用 emoji。
7. **手机优先**：≤640px 自动变底部抽屉。

## v2.401 增强
- **你不在时**：合上手札即记下读到哪；再打开时新条目标「新」，页签与 ◈ 出现未读点，概览顶部给一句摘要。
- **带进对话**：远方、风声、暗流、伏笔每条右侧的羽毛笔，把它追加进酒馆输入框（不自动发送）。
- **人物**：分「就在身边 / 在别处 / 久未露面」，卡片内显示亲近、信任（敌意高才出现），可搜索。
- **空世界引导**：三步开局代替一排「还没有记录」。
- **阅读偏好**：墨/纸两种底，小/中/大字号。
- **手势与无障碍**：手机左右滑切页；Esc 关闭；焦点锁在面板内、关闭后回到原处；页签有 aria 状态。
- **◈ 状态**：推演中外圈转一段琥珀弧，失败变赭红圈，有未读左上角亮点。

## v2.402 开发者面「工作台」（ui/console.js）
- 只加一层：给 #wa-panel 挂 `.wc` 类，全部新样式限定在其下；不改 PAGES、控件 id、renderBody/bindBody。
- 左侧分组导航（收藏 / 叙事 / 世界 / 工坊 / 系统），emoji 换线性图标，可星标收藏常用页。
- 每页自动补页头：页名 + 一句话用途 + 段落目录（点击跳到该段）。
- 命令面板 Ctrl/⌘+K：模糊搜 34 页与当前页所有段落。
- 宽屏切换；≤720px 全屏 + 顶部横向页签。
- 语义色收敛为四个：天青=信息、苔绿=成功、琥珀=警告、赭红=错误；数字与日志用等宽。

## v2.403 内容整理（头部 ≡ 按钮可开关）
- 不改任何文字、不移动任何节点：只加类、只把片段包进 span（textContent 逐字不变），关掉即原样。
- 段落 >5 的页默认只展开前两段，记住你展开过哪些；页头有「全部展开/收起」。
- 「缺席 / 不可用 / 未装载」诊断行收进页头一枚「N 项未装载」，点开才显示。
- 版本号、引擎文件名在正文里弱化为等宽小字；段落标题里的（N）变成徽章；只剩诊断行的段标「空」。
- 无头/jsdom 环境下两个新模块都只登记空壳，不进测试遍历面。

## v2.405 白话层与细节
- 版本号、开发代号（B6/G17/RX/OPV/EXV）、引擎文件名：在显示层整段去掉。日志与原始输出保留原文。
