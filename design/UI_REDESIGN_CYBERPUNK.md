# WorldAxis UI 重构：赛博朋克科幻控制台

## 设计哲学
**「世界操作系统的神经中枢」** —— 实时监控、精密操控的指挥中心。

## 核心组件

### 悬浮球（量子核心）
- 六边形 + 旋转粒子环
- 空闲：青色慢速脉搏
- 繁忙：琥珀色快速旋转
- 错误：红色闪烁故障

### 侧边栏
- 收起 60px / 展开 240px
- 当前页：青色左边框 + 背景光晕
- 悬停：白色 + 青色光晕

### 卡片系统
```css
.wa-card {
  background: var(--glass-dark);
  backdrop-filter: blur(12px) saturate(180%);
  border: 1px solid rgba(0,217,255,0.15);
  border-radius: 12px;
  box-shadow: 0 4px 16px rgba(0,0,0,0.4);
}

.wa-card:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 32px rgba(0,0,0,0.5), 0 0 20px rgba(0,217,255,0.4);
}
```

### 按钮
```css
.wa-btn-primary {
  background: linear-gradient(135deg, #00d9ff 0%, #7c3aed 100%);
  box-shadow: 0 0 20px rgba(0,217,255,0.4);
  border: 1px solid rgba(0,217,255,0.6);
}
```

### 开关（Toggle）
- 开启：青色发光轨道
- 关闭：灰色暗淡
- 过渡：流体动画 + 粒子轨迹

## 动效系统
- 页面过渡：滑入淡入（300ms ease-out）
- 悬浮：上浮 2px + 阴影加深
- 点击：缩小 scale(0.98) → 弹回
- 背景：缓慢移动六角网格 + 扫描线（CRT效果）

## 页面设计

### 概览页（Dashboard）
- 世界状态卡：当前时间（发光大字号）+ 推演进度环
- 系统监控：内存图表 + 引擎状态指示灯
- 快捷操作：存档/读档/推演控制

### 人物页
- 头像：圆形 + 发光边框（关系着色）
- 好感度：渐变进度条

### 日志页（终端风格）
- 等宽字体（Fira Code）
- 级别着色：ERROR红/WARN琥珀/INFO青/DEBUG灰

## 独特性来源
1. 非对称布局（打破居中对称）
2. 多层景深（渐变/模糊/光晕）
3. 赛博元素（扫描线/故障艺术/六角网格）
4. 功能性装饰（视觉元素对应系统状态）
