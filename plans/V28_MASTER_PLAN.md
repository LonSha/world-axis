## 零、缺失地图（六个空洞，先定位再列项）

产品自述没错，**错在重心**：现在是"每轮结算一次的全景快照"，不是"按人走的连续生活"。

| # | 空洞 | 现场读数（可复算） | 同类插件的通病 |
| :--- | :--- | :--- | :--- |
| **G1** | **退场角色无通路** | `npcBudget: 8`（backstage:118）、`sorted.slice(0, budget \|\| 8)`（:224）、排序键 `updatedAt`（:213）、`PEOPLE_CAP=48`（:31）⇒ 久未提及者永远排第 9 名之后，永不进推演 ⇒ 永不更新 ⇒ 永远排后面（自锁） | 记忆插件只记"提过的人"，没人提就冻结 |
| **G2** | **行动没有"成没成"** | `grep -n 'WA.act' engines/backstage.js` **零命中**；`act.js` 四档 `VERDICTS`（:899–906）从未进推演快照；`people` 只有 `location/action/intent`（:706） | 好感度 + 一句"状态"，不区分"想做"与"做成" |
| **G3** | **信息只有"知道/不知道"** | `misbelief` **0 命中**、`将错就错` **0 命中**、`拼图` **0 命中**；`people.knows` 只给前 10 个键（:229） | 有"知道/不知道"两态，没有"确信但错" |
| **G4** | **线是登记的不是长出来的** | `threads`/`foreshadow` 要显式 `plant/germinate`；`foreshadow-germination` 按"超时破土"（闹钟）；`currents` 快照 `slice(0,10)`（:249） | 随机事件表 / 任务列表 |
| **G5** | **选择没有排期** | `choices_recent` 回流（v2.404）只要求"结算"；`path-echo` 是**事后**回声；全仓无"未来应验条件"落点 | 选项 = 重掷骰子，或当轮就结清 |
| **G6** | **世界在生产，玩家在读面板** | 347/464 引擎默认开；34 页 / 1596 控件；182 源 / 2400t 预算；推演 24 字段 vs `story-window` 12 窗 16 痕 | 面板越堆越多，正文越来越像报表 |

**七件只有 WorldAxis 有的资产（差异化底盘，别人补不上）**

1. **原子提交 + 票据幂等**（`core/commit.js` / `staleGuard` / `undo.js`）—— 世界不半写、不重复推。
2. **认知边界**（`epistemic-view` / `intel` 四层 / `rumor` 传播链四层）—— 人物只按自己手里的版本行动。
3. **因果链与延迟后果**（`causal`：原因→条件→行动→直接后果→延迟后果）—— 后果可以"还没到"。
4. **分支对账与移植**（`branch-diff` / `branch-transplant`）—— 两条线能比、能移植"既视感"。
5. **三种时间的分离**（`clock` 世界钟 / `storyclock` 正文锚 / `playtime` 真实活动）—— 别人只有一个时钟。
6. **离线世界继续**（`offline-tick` 锚保护 + `offline-return` 编排）—— 你不在时世界也过了一夜。
7. **叙事节拍与倾向**（`tempo` 四挡 / `beat` / `story-tone` / `plot-gauge`）—— 走向可控，不是每楼都"合理"。

**因此本期的创新命题只有一句**：把"世界状态"变成**可感知、可追溯、可误解、可安静**的**生活**。
不是再造机制，而是让已有的七件资产在正文旁边转起来。

## 一、拓展线 36 项（EXV28-01～36·六组）

### X1 退场生活（6 项）· 命题：**镜头外的人，也有下一顿饭要愁**

> **组读数**：`npcBudget:8` / `updatedAt` 排序 / `PEOPLE_CAP=48`（退场自锁）；`living-world` 已有 `OCCUPATIONAL_ROUTINES`（作息网格）与 `metabolicLoop`（精力/饥渴/磨损）；`act` 有四档 `VERDICTS` 但不在推演链上。

| 编号 | 项 | 机制（落点） | 验收 / 边界 |
| :--- | :--- | :--- | :--- |
| EXV28-01 | 退场轮转推进 | `offstage-queue`：按**最久未被推进**（`lastStepAt`）取 K=3 人进推演"该他走一步" | 20 轮未提及者在 20 轮内被推进 ≥2 次；场景内人物不被挤掉。负控制：改回 `updatedAt` 必红 |
| EXV28-02 | 行动三态回执 | `people.step:{kind,verdict,evidence,witness}` 落 `act`；注入写"做到哪一步" | "决定去找"≠"找到了"；无证据的完成判未定。负控制：`evidence` 恒 `ok` 必红 |
| EXV28-03 | 作息落点 | 复用 `OCCUPATIONAL_ROUTINES`：答"此刻他在哪、在做什么、能否被撞见" | 同一人 3 个时段 3 个落点；不在场时答案来自作息而非编造 |
| EXV28-04 | 生计压力驱动 | 由钱/粮/伤/债（`belongings`/`metabolicLoop`）推出"他今天必须做什么" | 断粮者不会去喝酒；压力解除后行为回到常规 |
| EXV28-05 | 缺席的后果 | 他不在 ⇒ 班没人替 / 店关门 / 仇人动手（与 `ward-compact` 连坐同类） | 缺席 3 轮后能指出"因为他不在，谁吃了亏" |
| EXV28-06 | 久别再遇 | 复用 `reunionSubtext`：重逢读发酵史，**他自己也变了** | 重逢时给出"他变了什么"且能对上离场期间的行动记录 |

## 四、贯通场景（每批一条，六条串成一局）

1. **客栈**（批一）：同伴在城西追查，被轮转推进；留车辙；托小二打听，痕迹抵达。
2. **错信**（批二）：小二说"铁匠昨夜出门"，实为错信；同伴据此跑空；玩家投放"铁匠已死"的假消息，传到仇家耳里。
3. **长线**（批三）：从"同伴的承诺"长出支线；玩家没接，10 轮后线降级但留下"他一个人去了"。
4. **到期**（批四）：三日后火起（应验条件满足），后果落到"玩家那晚在喝酒"；不可逆。
5. **三时**（批五）：玩家离线两天回来，世界只走了 3 件事；正文时间与世界钟偏差 1 天，可读。
6. **换眼**（批六）：以同伴视角写一段插曲（他不知道玩家已离开客栈）；玩家读到一封信；世界安静了一轮。

验收点：**六批里没有任何一轮需要打开机制页**；每条后果都可追到"哪一轮/哪个人/哪次选择"。
