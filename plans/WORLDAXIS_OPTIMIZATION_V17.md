### OPV17-1 · 生理极限剧痛与应激惊恐的精神代偿
- **现状底座**：`engines/metabolism-clock.js` 维护体能代谢与毒理负荷，`engines/human-realism.js` 维护角色需求，但机能受损与精神创伤彼此完全割裂。
- **本期改造**：
  1. 引入精神惊恐冲击算法：当角色单次承受重击、骨折、恶性毒发或生命值跌破 30% 时，根据伤残严重度叠加 `psychicStress`；
  2. 惊恐指数突破角色意志阈值（`willpowerThreshold`）时，角色进入惊慌失措（`panic_flight`）或精神休克（`psychic_shock`）状态；
  3. 意志坚定特质（`firm_will`）与镇静止痛药剂可吸收并衰减惊恐负荷。
- **调度接口**：
  - `actionDesk.act('bio.applyPsychicStress', { actorId, shockLevel, cause })`
- **验收旅程与负控制**：
  - 正向：重伤角色在缺乏镇痛时惊恐爆发，动作命中率归零并向后退缩；
  - 负控制：对具备无畏特质或毫发无损的角色（`shockLevel <= 0`），断言绝不产生非零惊恐代偿。

### OPV17-2 · 四层总线深层动机与长程意图穿透
- **现状底座**：`engines/cascade-bus.js` 仅调度即时事件，`engines/intent-board.js` 意图板与底层物理遭遇脱节。
- **本期改造**：
  1. 建立自下而上的意图重塑穿透流：Layer 1 物理灾难与 Layer 2 生死受挫直达 Layer 3/4；
  2. 角色核心长程动机被动态修改（如安分守己的农夫在房屋被焚后将第一意图重塑为“流亡复仇”）；
  3. 意图重塑触发行动序列重构，拒绝呆板日常。
- **调度接口**：
  - `actionDesk.act('bus.penetrateIntent', { actorId, traumaticTrigger, newPrimeDirective })`
- **验收旅程与负控制**：
  - 正向：主角毁其家业，NPC 即刻将意图由“经商致富”覆写为“血海深仇”；
  - 负控制：未达到重大冲击量级的日常琐事（`weight < 80`），断言禁止篡改角色的终生核心动机。

### OPV17-3 · 微观空间私密环境对精神抚慰与冥想自愈
- **现状底座**：`engines/spatial-topology.js` 与 `engines/sanctuary-scramble.js` 仅计算物理容积与通行阻抗，缺乏空间心理学体验。
- **本期改造**：
  1. 为微观空间节点引入环境舒适度（`comfortRating`）与神圣/安宁庇护标签；
  2. 角色在温暖避风、静谧幽雅的环境中休眠或冥想，心理创伤与理智损伤以 3 倍速率愈合自愈；
  3. 潮湿恶臭地牢或阴森古墓持续施加微观精神压抑。
- **调度接口**：
  - `actionDesk.act('geo.evaluateComfort', { nodeId, actorId, durationHours })`
- **验收旅程与负控制**：
  - 正向：创伤角色在温泉别院静养 3 周期，理智值全面回满并抚平焦虑；
  - 负控制：处于漏风暴雨乱葬岗（`comfortRating < 0`），断言绝不可产生正面精神疗愈。

### OPV17-4 · 现场物证对犯罪动机与心虚神色的实时映射
- **现状底座**：`engines/spatial-trace.js` 仅记录痕迹物理留存，不与涉案角色情绪发生化学反应。
- **本期改造**：
  1. 涉案人关联系统：在微观足迹、血迹、凶器遗留物证上绑定暗中作案人标识；
  2. 心理战对抗：当涉案嫌犯重返物证未清除的作案节点，或在盘问中直面物证时，触发心虚检定；
  3. 失败者出现瞳孔震颤、冷汗直流、语无伦次等微表情破绽，直接大幅降低辨识难度。
- **调度接口**：
  - `actionDesk.act('geo.bindGuilt', { traceId, suspectId, interrogatorId })`
- **验收旅程与负控制**：
  - 正向：凶手面对带血匕首心理防线崩溃，主动坦白交代隐藏物证；
  - 负控制：无关无辜人员接受物证盘查，心虚度断言恒为 0，严禁假阳性破绽。

- **调度接口**：
  - `actionDesk.act('item.anchorKeepsake', { actorId, itemId, keepsakeType, emotionalValue })`
- **验收旅程与负控制**：

  - 负控制：普通无情感锚定的消耗品（如干粮绷带），断言绝不产生羁绊心结反馈。

### OPV17-6 · 市井传闻情绪极化与集体偏见社会回响
- **现状底座**：`engines/rumor.js` 与 `rumor-cognition.js` 仅记录传闻事实认知，缺乏群体心理极化。
- **本期改造**：
  1. 引入群体情绪极化模型：传闻在民间传播演变过程中，附带激化乘数（`hysteriaMultiplier`）；
  2. 当针对某一家族、宗门或外乡人的负面流言达到临界点，市民态度由“议论”激化为“排斥、围攻、砸毁铺面”；
  3. 角色在该区域将遭遇商贩拒售、旅馆拒宿等硬性社会制裁。
- **调度接口**：
  - `actionDesk.act('society.polarizeSentiment', { rumorId, targetFactionId, heatIncrease })`
- **验收旅程与负控制**：
  - 正向：妖言惑众传闻发酵后，整座小镇市民自发封锁客栈猎巫；
  - 负控制：若传闻真实度为 100% 的公正褒奖，断言禁止产生群体仇恨极化效应。

### OPV17-7 · 作息日常中的梦魇回溯与失眠离魂状态机
- **现状底座**：`engines/universal-routine.js` 严格按照时间表机械睡觉与起床。
- **本期改造**：
  1. 引入睡眠阶段心理检定：身负重大心理创伤（`trauma > 60`）的角色在入眠后概率触发“梦魇回溯（`nightmare`）”；
  2. 梦魇惊醒后，角色陷入失眠状态，夜半离开卧房在庭院游荡、擦拭佩剑或借酒浇愁；
  3. 次日晨间体力与精力恢复折半，并伴随神思恍惚负面状态。
- **调度接口**：
  - `actionDesk.act('routine.injectNightmare', { actorId, traumaEchoId })`
- **验收旅程与负控制**：
  - 正向：经历灭门的主角午夜梦回惊醒拔剑，体力恢复减半且双眼血丝；
  - 负控制：身心健康且无创伤负荷的角色（`trauma == 0`），断言睡眠恢复恒为满额，不触发梦魇状态。

### OPV17-9 · 全仓 355 引擎因果死循环与概率混沌阻尼器
- **现状底座**：`engines/health-preflight.js` 仅做静态拓扑环扫描，缺乏动态因果回音的能量衰减阻尼。
- **本期改造**：
  1. 引入因果能量衰减网络（`dampingNetwork`）：每一次因果反冲与仇恨回馈必须按物理对数衰减；
  2. 阻断“A报复B -> B报复A -> A再报复B”的死循环自激爆炸；
  3. 当检测到因果回响周期震荡超过 5 轮且未产生新变量时，强制注入时间遗忘与天命偶然扰动，平复死锁。
- **调度接口**：
  - `actionDesk.act('sys.dampenLoop', { loopKey, participants, decayRate })`
- **验收旅程与负控制**：
  - 正向：两个家族持续摩擦在经历 3 次相互报复后，仇恨强度自然衰减收敛为暗中冷战；
  - 负控制：单向发生的非闭环独立因果事件，阻尼器断言放行不予衰减干涉。
