### EXV16-1 · 微气候相变与极端介质传导引擎
- **机制原理**：
  - 支持通用空间介质的物态相变：水体结冰（`liquid_to_ice`）、高温水汽蒸发（`mist_fog`）、油脂燃烧火线蔓延（`oil_fire_spread`）、干燥土壤遇水泥泞化（`mud_quagmire`）；
  - 介质物相直接改写微观节点的通行阻滞系数（`frictionCoef`）、视听能见度阻抗与动能冲击吸收比；
  - 冰面增加打滑失稳风险，泥泞大幅降低移动速度并增加足迹残留深度。
- **调度接口**：
  - `actionDesk.act('env.simulatePhase', { regionId, nodeId, temperature, humidity, activeMedia })`
- **产品体验与负控制**：
  - 体验：护城河寒冬封冻，角色可冒险踏冰突击，但负重过大将踩碎薄冰坠河失温；
  - 负控制：密封保暖的室内节点温度恒定，严禁因室外降温触发室内水杯结冰相变。

### EXV16-2 · 生物机能毒素积蓄与生理解毒代谢引擎
- **机制原理**：
  - 建立全题材通用的毒理生物学模型，抽象为四大毒理分类：神经麻痹（`neuro_paralysis`，削减敏捷与感知）、组织腐蚀（`tissue_corrosion`，持续扣除体力并损伤脏器）、致幻失真（`hallucinogen`，扭曲有限视界与认知判断）、凝血窒息（`asphyxiation`，耐力代谢熔断）；
  - 毒素浓度遵循体内肝肾生理半衰期（`halfLifeMinutes`）自然分解，抗毒血清或解毒草药提供阶梯式中和速率。
- **调度接口**：
  - `actionDesk.act('bio.metabolizeToxin', { actorId, toxinType, dose, antidote })`
- **产品体验与负控制**：
  - 体验：中伏中毒箭后，角色视野模糊摇晃且敏捷骤降，必须在毒发攻心前服用解药并卧床排毒；
  - 负控制：健康无毒角色服用解毒剂，断言其生理机能指标绝对不受解毒中和影响，严禁负数毒性溢出。

### EXV16-3 · 视听超视距光热与烟火信号传导引擎
- **机制原理**：
  - 在缺乏现代电信的古典/冷兵器/废土情境中，建立超视距物理光热传播模型（烽火、信号弹、狼烟、响箭、魔光结界）；
  - 传播范围基于发射高度（`altitude`）、空间视线几何阻挡（山脉、城墙）与气象能见度（浓雾、暴雨阻光）；
  - 处于视线范围内的哨卡据点自动产生“目击察觉事件”，触发连带戒备链。
- **调度接口**：
  - `actionDesk.act('geo.broadcastSignal', { sourceNodeId, signalType, altitude, power, visibilityCondition })`
- **产品体验与负控制**：
  - 体验：要塞夜间发射红色信号弹划破长空，方圆 30 里内三处哨所同时观测到信号并紧急敲响战鼓；
  - 负控制：暴风雨低能见度或深处峡谷阴面发射信号，断言超距据点绝不可无因果感知，拦截全知视线。

### EXV16-4 · 全题材地下黑市汇流与走私违禁供应链引擎
- **机制原理**：
  - 建立官方管制与地下流通的走私价值流模型。当特定物资（盐铁、禁药、魔法石、枪支核心）被列为关卡违禁品时，其合法流通受阻，黑市溢价系数（`contrabandPremium`）飙升 200%～500%；
  - 走私线路具备风险等级，结合随身多层暗格（`personal-inventory`）隐蔽值与哨卡查验严苛度，动态判定走私货物是否被扣押没收；
  - 成功走私向黑市货架注入高稀缺现货，走私失败触发全城缉捕与信誉清零。
- **调度接口**：
  - `actionDesk.act('market.smuggleContraband', { routeId, smugglerId, cargoItems, stealthRating })`
- **产品体验与负控制**：
  - 体验：商客利用行囊暗格成功将禁运药品偷运进城，在黑市高价抛售获得暴利；
  - 负控制：走私货物列表中若不包含任何管制违禁品，系统直接拦截并拒绝走私路由判定。

### EXV16-5 · 空间群体恐慌共振与踩踏踩空动力学引擎
- **机制原理**：
  - 微观社会群聚物理学模型。当封闭微观节点（避难所、集市、广场、剧场）爆发突发危机时，人群恐慌指数根据人流密度（`density`）与视界可视度产生非线性共振放大；
  - 恐慌突破临界后，人群自发向唯一开敞出口盲目冲撞，引发通道阻塞（`choke_lock`）；
  - 相互推挤与绊倒踩空触发动力学踩踏伤害，造成群体性骨折休克。
- **调度接口**：
  - `actionDesk.act('geo.triggerStampede', { zoneId, panicSource, crowdDensity, exitCapacity })`
- **产品体验与负控制**：
  - 体验：剧院突发起火，观众争相挤入狭小门洞导致踩踏，多人受伤滞留；
  - 负控制：在开敞空旷广场（出口无界）且人群密度低于临界值时，断言绝不产生踩踏阻塞伤害。

### EXV16-6 · 多角色视界非对称谎言与物证比对裁决引擎
- **机制原理**：
  - 落实非全知社会学裁决。当多名角色就某一案情或历史事件作出冲突口供时，系统基于各自的微观视窗（`lens-culling`）与声学截获记录核验其陈述真伪；
  - 结合案发现场残留的环境物证痕迹（`spatial-trace`，如毛发、血迹残留度、鞋印深度），执行交叉证据链对账；
  - 识破虚假证词后，对说谎者标记信用破产与欺瞒罪状，形成司法/声誉事实。
- **调度接口**：
  - `actionDesk.act('society.crossExamine', { testimonyMap, traceIds, investigatorId })`
- **产品体验与负控制**：
  - 体验：嫌疑人宣称案发当夜在驿站就寝，但现场地毯留存其特有足印痕迹且未被暴雨冲刷，谎言被当场戳穿；
  - 负控制：在没有任何物证支持且视界记录空白的情境下，系统判定为“疑罪从无/证据不足”，断言严禁凭空定罪。

### EXV16-7 · 随身武器装备耐久损耗与物理形变破损引擎
- **机制原理**：
  - 道具物理强度与结构应力模型。防具、兵器、工具在承受极端物理载荷（重击、高温热应力、强酸腐蚀、频繁开山凿石）时累积物理应力（`materialStress`）；
  - 耐久按载荷对数阶梯损耗，破损阶段分为：微磨损（`pristine`）→ 性能钝化（`dull`）→ 结构裂纹（`cracked`）→ 完全折断损毁（`shattered`）；
  - 折断破损的武器失去杀伤力，防具防御阻抗归零并可能刺伤穿戴者。
- **调度接口**：
  - `actionDesk.act('item.applyStress', { itemId, stressType, loadMagnitude, currentDurability })`
- **产品体验与负控制**：
  - 体验：持普通精钢长剑强行硬挡巨石冲击，长剑应声崩断为两截，角色被迫转入空手肉搏；
  - 负控制：处于静止存放于干燥安全箱内的道具，物理应力恒为 0，断言禁止产生莫名损耗。

### EXV16-8 · 微观空间掩体物理防护与流弹穿透破片引擎
- **机制原理**：
  - 通用掩体弹道学模型。微观作战节点中的掩体材质（砖石、实木、薄铁皮、沙袋、结界壁）具备固定的动能衰减阈值（`stoppingPower`）；
  - 高动能飞行道具（弩箭、枪弹、飞剑、爆炸破片）穿透薄弱掩体后，按剩余动能对掩体后目标造成衰减贯穿伤；
  - 坚固石质掩体吸收全部动能并产生飞溅碎屑流弹，提供高防跳弹护角。
- **调度接口**：
  - `actionDesk.act('combat.resolveCover', { attackerId, targetId, coverMaterial, projectileEnergy })`
- **产品体验与负控制**：
  - 体验：逃亡者蹲伏在厚重石阶掩体后，成功规避了迎面射来的暴风骤雨般弩箭；
  - 负控制：角色躲藏在纸质屏风后，面对重型破甲箭断言穿透率为 100%，掩体提供的防护阻抗必须为 0。
