### EXV17-1 · 混沌蝴蝶长程多米诺因果拓扑引擎
- **落盘核心**：`engines/butterfly-cascade.js`
- **机制原理**：
  - 构建非线性微观因果放大网络（`ButterflyCascade`）。每个物理扰动节点包含初始势能（`energy`）、介质放大系数（`amplifier`）与分支延迟（`delayTurns`）；
  - 当微观事件（如某药材库意外失火、刺客遗落一枚特定铜钱）发生时，录入蝴蝶种子；
  - 伴随时钟推进，蝴蝶种子沿社会拓扑链式传导并指数级放大，最终在数轮后爆发为宏观系统性危机（粮价暴涨暴动、门派决裂、大战序幕）。
- **调度接口**：
  - `actionDesk.act('causal.triggerButterfly', { seedEventId, initialEnergy, targetTopologyChain })`
- **产品体验与负控制**：
  - 体验：玩家在第一章无意踢翻的一盏油灯，在第五章演变为烧毁粮仓诱发全城起义的蝴蝶风暴；
  - 负控制：若扰动能量小于环境吸收阻尼阈值（`energy <= dampingFloor`），因果链断言自然平息，严禁无限凭空放大。

### EXV17-2 · 深层心智创伤、执念与精神失常心理学引擎
- **落盘核心**：`engines/psyche-trauma.js`
- **机制原理**：
  - 全题材通用的深层心智防御模型。角色具备心智稳定性（`sanityIndex` 0~100）与偏执执念（`obsession` 0~100）；
  - 当承受重大情感撕裂（背叛、至亲惨死、信仰破灭）时，累积深层创伤（`trauma`）；
  - 当创伤突破临界且缺乏有效慰藉时，角色进入认知失调（否认事实）、极端偏执狂化，或发生“心智黑化（`blackening`）”，彻底逆转其善恶阵营与决策逻辑。
- **调度接口**：
  - `actionDesk.act('mind.inflictTrauma', { actorId, shockLevel, traumaType, sourceId })`
- **产品体验与负控制**：
  - 体验：正道首徒遭遇同门构陷与亲族诛灭，心智彻底黑化，立下血誓化身复仇修罗；
  - 负控制：对具备天生圣人/无情道心（`immunePsychic`）的角色，断言黑化转化判定直接拒绝，严禁突兀人设崩坏。

### EXV17-3 · 阴谋集团权谋编织与政变颠覆引擎
- **落盘核心**：`engines/conspiracy-weaver.js`
- **机制原理**：
  - 模拟地缘权力斗争的核心骨架。支持地下密谋结盟（`cabal`）、密室名单（`conspiracyRoster`）与政变步骤清单（`coupPhases`）；
  - 阴谋编织包含：暗中拉拢禁卫军统领、转移私藏违禁军械、伪造矫诏弹劾文书、选定午夜行动发起政变；
  - 结合信息保密性检定，被官方侦破则全员问斩，政变成功则全盘清洗朝堂或宗门高层。
- **调度接口**：
  - `actionDesk.act('faction.hatchConspiracy', { cabalId, ringleaderId, targetAuthorityId, phases })`
- **产品体验与负控制**：
  - 体验：暗流涌动的帝都，三家豪门历经数月密谋，在一场宫廷夜宴上摔杯为号发动政变；
  - 负控制：密谋成员忠诚度高于背叛阈值（`loyalty >= 70`）或缺乏正当篡权利益驱动，断言拒收政变签署。

### EXV17-4 · 意识形态模因共振与信仰狂热引擎
- **落盘核心**：`engines/ideology-memetics.js`
- **机制原理**：
  - 模拟思想、教条、邪说或文明信念在人群中的传播动力学；
  - 模因（`Meme`）具备感染力（`infectivity`）、变异率（`mutationRate`）与狂热排他性（`fanaticism`）；
  - 当群体狂热度突破临界，自发触发宗教裁判、异端审判猎巫、狂热圣战或反智毁灭风暴。
- **调度接口**：
  - `actionDesk.act('culture.broadcastMeme', { memeKey, sourceRegionId, dogmaContent, intensity })`
- **产品体验与负控制**：
  - 体验：末日教派在流民中传播飞升教义，数千人集体狂热冲击官府求取洗礼；
  - 负控制：在一个智识启蒙度极高、民生安居乐业的节点，低俗模因断言被理性免疫自然阻断。

### EXV17-5 · 戏剧性悬念弧光与契诃夫之枪引爆引擎
- **落盘核心**：`engines/dramatic-tension.js`
- **机制原理**：
  - 引入文学叙事学中的“契诃夫之枪（`Chekhov's Gun`）”法则：第一幕挂在墙上的枪，第三幕必须打响；
  - 允许标记剧情中的关键伏笔（一瓶未鉴定的毒药、一块带血玉佩、一封隐秘婚约）；
  - 引擎追踪伏笔闲置时间与当前场景张力（`tensionIndex`），在剧情最高潮时作为命运逆转的关键抓手强制出场。
- **调度接口**：
  - `actionDesk.act('drama.primeGun', { gunId, anchorEntityId, foreshadowText, detonationTension })`
- **产品体验与负控制**：
  - 体验：开局无意捡到的生锈铁片，在最终绝境大战时赫然是开启远古结界的无上钥匙；
  - 负控制：若伏笔所依托的实体已被物理彻底销毁熔化，断言该契诃夫之枪永久失效哑火，严禁机械降神。

### EXV17-6 · 宏观时代浪潮与文明生态周期演化引擎
- **落盘核心**：`engines/epoch-tide.js`
- **机制原理**：
  - 推动宏观世界由稳定期向大变局演化。时代浪潮（`EpochTide`）涵盖冰河严冬、灵气衰竭、废土辐射暴、大航海地理大发现；
  - 时代浪潮直接覆盖改写全域物理底层常数（如全图气温骤降 25℃、魔法消耗翻倍、通航成本暴降）；
  - 迫使所有国家、势力与凡人改变生存策略。
- **调度接口**：
  - `actionDesk.act('world.shiftEpoch', { epochType, severity, durationEpochTurns })`
- **产品体验与负控制**：
  - 体验：天下突降百年不遇的漫长寒冬，北境蛮族被迫南下争夺温暖粮仓，世界进入乱世剧本；
  - 负控制：在正常时代未发生任何地壳或天象异变时，断言禁止凭空产生极端的宏观时代突变。

### EXV17-7 · 道德两难伦理电车困境博弈引擎
- **落盘核心**：`engines/moral-dilemma.js`
- **机制原理**：
  - 动态生成具有深度人性张力的不可兼得绝境（`TrolleyDilemma`）；
  - 选项 A：牺牲挚爱拯救一城黎民；选项 B：弃城突围独活至亲；
  - 角色基于其深层价值观、羁绊权重与功利主义效用函数做出决断，承受巨大的道德创伤，并重塑社会各界对其评价。
- **调度接口**：
  - `actionDesk.act('drama.poseDilemma', { dilemmaKey, decisionMakerId, branchA, branchB })`
- **产品体验与负控制**：
  - 体验：城破在即，守将面临“炸毁民房阻断追兵”还是“全军战死”的决绝取舍，两难抉择逼出真实人性；
  - 负控制：若局面存在第三条和平破局通路，断言禁止强加二极管式道德电车困境。

### EXV17-8 · 非对称认知战争与视界虚假现实投毒引擎
- **落盘核心**：`engines/perception-manipulation.js`
- **机制原理**：
  - 打破角色之间的“全知透明”，支持主动伪造认知（`PerceptionPoisoning`）；
  - 允许角色制造虚假伤亡名册、释放假撤退军情、散布主角已死的误导性铁证；
  - 目标角色根据受污染的认知地图作出决策，直至亲临现场发生“认知崩塌（`epiphany`）”。
- **调度接口**：
  - `actionDesk.act('society.forgeIllusion', { forgerId, targetVictimId, falseBeliefFact, crediblityScore })`
- **产品体验与负控制**：
  - 体验：谍战之中，主角故意向叛徒泄露假藏身处，诱导敌方主力扑空并落入伏击圈；
  - 负控制：目标角色已身在现场且亲眼目睹真实事实，断言虚假现实投毒直接判定为识破（`unmasked`）。
