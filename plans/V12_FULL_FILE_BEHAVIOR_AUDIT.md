## 处置规则

- `behavior-wired`：优先做跨域消费者和产品路径复核，不默认改动。
- `read-consumer`：检查是否为玩家工作台、叙事投影、诊断或模型输入；只读不等于缺陷。
- `entry-needed`：确认是否由宿主生命周期、动态属性或 UI 间接调用；确认后才能决定融合或新增入口。
- `ui-or-host-entry`：检查主题/宿主注册是否正常，不把样式或宿主挂载误判为业务孤岛。
- 本报告仍是静态行为证据，不替代真实运行时验证；动态调用、加载顺序和外部供应商行为仍需专项复核。
