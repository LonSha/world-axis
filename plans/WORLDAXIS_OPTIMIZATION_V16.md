### OPV16-1 · 微观代谢与极端环境负荷的双向代偿
- **现状底座**：`engines/metabolism-clock.js` 维护角色的体力、精力与饥渴，`engines/environmental-hazard.js` 维护高低温、毒瘴、辐射等物理侵蚀，二者处于单向平行状态。
- **本期改造**：
  1. 建立机能抵御负荷算法：角色在极端恶劣环境（如暴风雪 -20℃ 或炽热 50℃）下，维持体温需要以正常 2.5～4.0 倍速率消耗卡路里与体力储备；
  2. 当体力与热量储备耗尽（<= 0）时，进入代偿衰竭状态，机能伤害由轻度转化为不可逆组织器官损伤；
  3. 引入防具/护甲保暖系数（`thermalInsulation`）与药物耐受抵消代偿消耗。
- **调度接口**：
  - `actionDesk.act('bio.applyHazardLoad', { actorId, hazardContext, durationMinutes })`
- **验收旅程与负控制**：
  - 正向：未穿御寒装备的角色在极寒中徒步 30 分钟，体力加速耗尽并触发“冻伤昏厥”；
  - 负控制：若角色处于密封温控恒温仓（`hazardLoad=0`），断言绝不可产生加速代偿消耗。

### OPV16-2 · 四层总线异步突发事件中断与优先级抢占
- **现状底座**：`engines/cascade-bus.js` 仅具备定周期的 `dispatchPulse()` 顺序脉冲流，突发危机无法立即抢占打断当前角色行为。
- **本期改造**：
  1. 引入优先级中断通道（`interrupt(priority, eventPayload)`），支持灾难爆发（`catastrophe`）、暗杀袭击（`assassination`）、警报拉响（`alarm`）；
  2. 抢占中断将强制清空下三层（中层机能、行为决策层、社会外联层）当前正在执行的日常动作队列；
  3. 角色状态被重置为“应激警备（`stress_alert`）”或“紧急避难（`evacuation`）”。
- **调度接口**：
  - `actionDesk.act('bus.interrupt', { priority, reason, affectedNodeIds, emergencyType })`
- **验收旅程与负控制**：
  - 正向：晨读 NPC 听到防空警报/灭门示警瞬间中断诵读，立刻转向防空洞或拔剑警戒；
  - 负控制：低优先级杂音或虚假恶作剧无法突破抢占阈值（`priority < threshold`），断言原有行为流程不被中断。

### OPV16-3 · 同域动线挤压仲裁的动能损耗与伤损判定
- **现状底座**：`engines/spatial-conflict.js` 在微观空间冲突中仅输出简单的让行者、争夺胜利者与阻断标志，缺乏物理动能交互与挫伤代价。
- **本期改造**：
  1. 结合角色体格（`mass`）、移动速率（`velocity`）与通道容积（`capacity`），计算碰撞冲击动量；
  2. 争夺失利方不仅被挤出空间，还将按冲击动量承受体力削减与挫伤（`contusion`）；
  3. 在极度狭隘通道（宽度 < 0.8m）发生推挤时，双方皆承受装备耐久损耗。
- **调度接口**：
  - `actionDesk.act('geo.resolveKinetic', { nodeKey, participants, urgency })`
- **验收旅程与负控制**：
  - 正向：两名逃难者在狭窄渡船跳板上争夺登船位，体格优势者冲开对手，弱者跌入水洼并受到扭伤减速惩罚；
  - 负控制：若通道宽度宽裕（`capacity >= 5`），仲裁直接判定和平并排通过，断言禁止产生任何非零冲突损耗。

### OPV16-4 · 物证与感官痕迹的环境介质吸附与异化
- **现状底座**：`engines/spatial-trace.js` 仅按固定半衰期衰减血迹、足迹与气味。
- **本期改造**：
  1. 引入材质介质吸附系数：多孔泥土、毛毯与未油漆木材对气味与体液具备高吸附性（衰减周期延长 300%）；
  2. 引入流动介质冲刷：湍急河流、倾盆大雨以对数级速率清洗可溶性痕迹；
  3. 引入化学与极端高温异化：火焰焚烧将血迹转化为不可辨识的碳化杂质，侦查检定要求大幅提升。
- **调度接口**：
  - `actionDesk.act('geo.evolveTrace', { traceId, mediumType, weatherContext })`
- **验收旅程与负控制**：
  - 正向：室内羊毛地毯上的毒药微量残留历经 48 小时仍能被嗅觉检定捕获；暴雨冲刷下的石板路足迹在 15 分钟内彻底消失；
  - 负控制：不可溶微观刻痕（如匕首划痕）在纯水冲刷下断言绝对留存，降解率恒为 0。

### OPV16-5 · 多层暗格搜查的对抗博弈与暴力破坏检验
- **现状底座**：`engines/personal-inventory.js` 现已支持暗格感知检定，但搜查者缺乏“起疑后强拆破坏检查”的博弈后续。
- **本期改造**：
  1. 增加强拆破坏检验（`forceInspect`）：当搜查者直觉判定异常或持有违禁线报但常规搜身未发现时，可破坏物品外壳或划开衣物内衬；
  2. 破坏性检查可无视暗格隐蔽阈值直接起获物品，但伴随物品永久损毁（`destroyed`）与角色声誉/阵营信任崩溃代价；
  3. 搜查落空惩罚：若强拆后未发现违禁品，搜查方承受高额赔偿与外交交涉惩罚。
- **调度接口**：
  - `actionDesk.act('item.forceInspect', { inspectorId, targetId, itemKey, cause })`
- **验收旅程与负控制**：
  - 正向：守卫起疑后划破走私犯马鞍，夹层中的密信暴露无遗；
  - 负控制：搜查者无正当嫌疑依据且未持搜查令时，断言严禁执行破坏性搜身。

### OPV16-6 · 市井动线交汇视线阻断与盲区背刺仲裁
- **现状底座**：`engines/social-encounter.js` 仅判定视线相交与擦肩而过，缺乏空间死角盲区（Blindspot）潜行与近距离伏击模型。
- **本期改造**：
  1. 结合微观空间遮蔽物（屏风、货架、拐角柱）与视线朝向锥角（120 度前方视野），计算背向视野盲区；
  2. 尾随者利用人流掩护与死角接近目标，当进入 1 米范围且未被察觉时，获得“近距伏击占位（`backstab_ready`）”；
  3. 目标可依靠微弱声响或第六感直觉进行盲区感知对抗检定。
- **调度接口**：
  - `actionDesk.act('stealth.checkBlindspot', { stalkerId, targetId, environmentNoiseDb })`
- **验收旅程与负控制**：
  - 正向：刺客在喧闹酒馆集市（65dB 背景噪音）借助屏风死角摸到目标背后，达成完全潜行；
  - 负控制：目标身处空旷且安静（20dB）的密室中央，背向接近无论潜行值多高断言必因足音暴露。

### OPV16-7 · 全题材作息表反骨偏离与应激滞留重构
- **现状底座**：`engines/universal-routine.js` 提供了周期性作息模板，但在外部局势剧变时缺乏主动抗命偏离逻辑。
- **本期改造**：
  1. 引入意志偏离计算：当角色忠诚度崩解、生命受到致命威胁或受巨额贿赂时，触发“违背作息（`deviate`）”；
  2. 偏离行为支持滞留避难（`bunker_down`）、提前潜逃（`abscond`）或旷工反叛（`rebellion`）；
  3. 偏离事件被广播至管理中枢，引发组织点名巡检与通缉警戒。
- **调度接口**：
  - `actionDesk.act('routine.deviate', { actorId, routineId, triggerReason })`
- **验收旅程与负控制**：
  - 正向：当得知今夜官兵将清洗兵营时，原本应就寝的巡警果断旷工潜逃；
  - 负控制：角色忠诚度为满值且无任何危机刺激时，偏离判定恒返回拒绝（`deviate_rejected`）。

### OPV16-8 · 三插件跨界因果投影的事务原子性保障
- **现状底座**：`engines/bridge.js` 与 `engines/phone-bridge.js` 负责与 LonSha / RubyPhone 通信，但多步骤跨插件因果缺乏两阶段事务提交（Two-Phase Commit）。
- **本期改造**：
  1. 构建跨界原子事务锁（`atomicTransact`）：包含 `prepare`、`commit` 与 `rollback` 三态；
  2. 若 WorldAxis 扣除物资成功，但因网络或宿主异常导致 RubyPhone 状态未能同步，自动触发物理物资原路返还；
  3. 保障与 LonSha 记忆投影的一致性：世界物理事件未落盘前，绝不向 LonSha 发送虚假事实快照。
- **调度接口**：
  - `actionDesk.act('bridge.atomicTransact', { transactionId, phase, payload, rollbackHandler })`
- **验收旅程与负控制**：
  - 正向：通过手机转账购买补给，手机扣款与背包入库同步完成，产生双向确认日志；
  - 负控制：模拟外部插件通讯超时异常，事务中断，WorldAxis 背包已扣除款项自动全额回滚，断言账目守恒零差错。

### OPV16-9 · 347 引擎全局拓扑环路死锁断路与自愈
- **现状底座**：`engines/health-preflight.js` 具备静态一致性检查，但面对多引擎运行时循环依赖锁缺乏动态破环能力。
- **本期改造**：
  1. 建立运行时等待有向图（Wait-For Graph）：监控总线、空间冲突、交易锁与行囊占用的循环依赖；
  2. 当检测到角色 A 等待 B、B 等待 C、C 反向等待 A 超过 5 轮次时，断定为逻辑死锁；
  3. 死锁断路器（`breakDeadlock`）强制挑选中断代价最低的角色赋予“强制放弃退出（`forced_yield`）”，破除环路。
- **调度接口**：
  - `actionDesk.act('sys.breakDeadlock', { dependencyGraphSnapshot })`
- **验收旅程与负控制**：
  - 正向：三名角色在三角形狭道内互相让行卡死，断路器触发，其中一人被强制推入侧边空地，系统恢复流动；
  - 负控制：正常线性排队（有终点角色成功移动）未成环，断言严禁误触发断路强制清退。
