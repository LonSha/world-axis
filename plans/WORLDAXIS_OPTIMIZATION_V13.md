# WorldAxis 优化提升计划：OPV13-1 至 OPV13-9
> **工程归属**：WorldAxis 活世界引擎系统 (`/home/user/wa_opt1`)  
> **基线**：`v2.301.0` / commit `296c258`  
> **状态**：`proposed`（2026-11-06 立）  
> **目标**：不堆砌无消费的诊断字段，聚焦人物生理熔断、复杂伏笔生命树、守恒通胀与黑市、险道季节天堑、谣言异化、潜台词张力包、非二元检定代价、期刊思潮指数与调度心跳编排九大实质优化。

### OPV13-1 · 人物动机仲裁与压力熔断的物理生理因果
- **现状底座**：`engines/motive-arbitration.js` 与 `engines/affect.js` 具备动机仲裁和情绪计算，但未与生理极限（体力枯竭、重度失血、创伤震荡）挂钩。
- **本期改造**：
  1. 引入生理熔断判定：当耐力值耗尽或累计压力超过阈值时，强制返回物理硬关闭动作（`hard_lockout: 'faint' | 'collapse' | 'mute_panic'`）；
  2. 该动作在 `actionDesk` 调度中拥有最高拦截级，不可被外层提示词软性覆盖；
  3. 产生不可逆的生理伤痕（`physiological_scar`）。
- **验收旅程**：连续施压使角色体力归零后，后续所有社交和行动被物理硬熔断拦截；产生虚弱回声，直到获得真实医疗救治。

### OPV13-2 · 复杂事件伏笔的长周期生命树与回收失真
- **现状底座**：`engines/foreshadow.js` 与 `engines/causal.js` 具备伏笔埋设与因果链，但跨章节演进缺乏生命周期与过期机制。
- **本期改造**：
  1. 构建伏笔四态生命模型：`planted`（埋设）→ `dormant`（潜伏发酵）→ `harvested`（回收揭示）/ `decayed`（失效淡忘）；
  2. 伏笔在潜伏期可能因新事件介入产生“误导分支”（`distorted_lead`）；
  3. 回收时根据证据链完整度返回真实闭环或伪真相闭环。
- **验收旅程**：埋下暗杀伏笔后，若经历长时间未触发且局势变迁，伏笔自然转化为失效陈旧线索或被误认为意外事故，不再死板等待触发。

### OPV13-3 · 守恒经济网的跨区域通胀、供需失衡与走私黑市
- **现状底座**：`engines/economy.js` 与 `engines/freight.js` 实现了物资物流与短缺扣减，但价格仍相对刚性，缺乏金融与黑市杠杆。
- **本期改造**：
  1. 引入区域物价动态敏感曲线：现货存量低于安全库存时触发价格指数阶梯暴涨；
  2. 官方通道受阻时，自发生成高风险走私路线（`contraband`），以 300% 暴利吸引行商冒险；
  3. 走私伴随查扣、没收与信用破产风险。
- **验收旅程**：城镇铁矿断供 3 轮后，官方铁价翻倍，地下黑市开市；玩家可选择高价走私牟利，但一旦被巡防查获将承担巨额罚金与信用断崖。

### OPV13-4 · 地理通达度演化、险道阻隔与季节性天堑
- **现状底座**：`engines/geo-tracker.js`、`engines/farfield.js` 与 `engines/horizon.js` 计算了距离与行进，但地形连通性未与自然环境动态耦合。
- **本期改造**：
  1. 地图边拓扑增加动态通行阻力因子（`traversabilityFactor`）；
  2. 暴风雪、泥石流、汛期等极端气象将某些关键通道状态置为 `blocked`；
  3. 强行通过需执行高难度体能检定，失败将发生物资沉没或队伍失散。
- **验收旅程**：冬季北方峡谷被暴雪阻断，商队自动改道耗时翻倍的平原迂回路线；若玩家强行翻山，触发人员冻伤与货物倾覆结算。

### OPV13-5 · 认知信念网的传闻衰减、谣言异化与情报搜集
- **现状底座**：`engines/epistemic.js`、`engines/intel.js` 与 `engines/rumor.js` 支持非全知视角，但信息在口口相传中的变异缺乏系统支持。
- **本期改造**：
  1. 传闻网络中加入传播跳数衰减与文化偏好过滤器；
  2. 每经过一次中继转述，有确定性概率剔除核心量词并注入受众阵营的猜忌偏见（`biasDistortion`）；
  3. 建立反谍报情报勘验写口，消耗资金与时间核实情报真实度。
- **验收旅程**：一则“城防军招募民兵”的公告经 3 次异地转述后，北方领地接收到的情报异化为“南方准备发动越界突袭”，直接影响领主决策。

### OPV13-6 · 叙事潜台词解码与情境张力动态调节
- **现状底座**：`engines/scene-narrative.js` 与 `engines/backstage.js` 负责情境描绘与回声，但人物言语与其内心动机之间的张力缺乏统一约束。
- **本期改造**：
  1. 场景上下文生成时计算双方心理张力值（`tension_grade: low | medium | high | lethal`）；
  2. 根据张力级别注入“潜台词防线”（如心口不一、试探虚实、言辞带刺）；
  3. 拦截毫无意义的空洞客套与过度热情的模板化回复。
- **验收旅程**：在谈判死局中，双方言辞极度克制但暗藏威胁，行动桌记录了潜台词真实意图；玩家若能敏锐听出弦外之音即可解锁隐藏妥协方案。

### OPV13-7 · 行动检定阶梯与非二元代价（代价成功与有益失败）
- **现状底座**：`engines/act.js`、`engines/success-grade.js` 实现了检定规则，但反馈多为纯粹的成败判定。
- **本期改造**：
  1. 检定结果扩展为五档光谱：`critical_success` / `costly_success`（成功但付出意外代价）/ `partial_progress` / `insightful_failure`（失败但获得关键线索）/ `catastrophic_failure`；
  2. 代价包含装备损坏、人情消耗、隐秘暴露；
  3. 失败启发提供后续检定的难度减免。
- **验收旅程**：撬锁检定掷出 `costly_success`：大门成功打开，但撬棍折断并触发了门铃轻响，迫使玩家在有限倒计时内搜刮撤离。

### OPV13-8 · 世界内期刊舆论发酵与社会思潮推动
- **现状底座**：`engines/periodicals.js` 支持报刊文章生成与排版，但未深入反馈到城市宏观政治思潮中。
- **本期改造**：
  1. 期刊发布后按发行量在平民、工匠、商会、贵族中积累舆论倾向点数（`public_sentiment`）；
  2. 当特定社会阶层的愤怒指数超过警戒线时，触发全城公共事件（如怠工抗议、市民请愿）；
  3. 市政当局可选择出台安抚补贴或严禁查封该报社。
- **验收旅程**：连续发布揭露行会偷工减料的调查报道，市民愤怒值突破阈值引发集会，倒逼市政议会召开紧急特别质询会。

### OPV13-9 · 中央场景行动桌全生命周期挂钩与自动编排
- **现状底座**：`engines/action-desk.js` 已承接 250+ 写口，但缺乏全局时序的自驱心跳调度。
- **本期改造**：
  1. 落地 `actionDesk.orchestrate({ turns, elapsedDays })` 全局心跳编排器；
  2. 按严密顺序结算：物理环境演变 → 物流在途推进 → 承诺期限核验 → 伤痕记忆衰减 → 舆论思潮积分；
  3. 单次心跳聚合产出完整世界动态事件摘要。
- **验收旅程**：单次调用 orchestrate 心跳推进 3 天，全城物流自动到货、过期承诺触发违约、暴雪封山路线阻断，全部自洽结算并输出事件清单。
