# WorldAxis 拓展、拓宽与创新计划：让世界形成自己的行为与历史

状态：**待实施的产品计划，九项均不是已交付功能**。制定日期：2026-10-22。
基线：`c6ff687` / `2.231.0`。配套：[优化提升九项](WORLD_PLAY_OPTIMIZATION_9.md)。

## 差异化主张

不再以“比别人多几十个模块”定义 WorldAxis。下一代的特征应当是：**人物的有限时间与有限认知，经过协作、知识传承和公共建设，形成一个有路径依赖的世界；历史会改变后续可用的行动，而不只是留在摘要里。**

本计划的“独有”是本项目拟形成的机制组合与玩家体验，不声称这些单一概念在学术界或所有游戏中史无前例。九项是相对已读源码的明确新增行为；关键词零命中不是不存在的证据。若施工时发现局部已有实现，直接复用，只交付此处定义的行为增量，不为了维持“原创”标签再造副本。

### 不重复建设的已知邻居

- `agency/plan/act` 已执行 NPC 行动；IN-1 增加动机竞争和价值取舍，不另造执行器。
- `worldLab` 不止三臂对比，已有 simulate/report/adopt/advance；IN-2 增加角色自己的有限预期与事后学习，不宣称新增反事实实验室。
- `intel/rumor/noesis/opinion` 已处理知情、失真、传播、舆情；IN-3 增加有限深度的“彼此是否知道”和共同约定。
- `inst` 有任职、权限、提案、批准、违约；IN-4 增加规则如何由实践形成、被接受或修订，不重写权限引擎。
- `research/training` 已有成果与个人成长；IN-5 增加技术谱系、传授与本地变体，不再新增同名研究模块。
- `world/production/freight/aftermath` 已有地点、设施、运输和修复；IN-6 增加服务网络与公共投资的拓扑效应，IN-7 增加可再生资源的反馈。
- `family/inst/chronicle/sediment` 已有资产交接、职位交接与历史；IN-8 增加被人承接或拒绝的社会遗产，不转移私人记忆。
- `era-cycle` 已有周期阶段，evolution 已有事件阶段推进；IN-9 增加由多个实际条件共同促成、并有滞回的局部时代转型，不换名字再造周期条。

每项沿用现有 store/clock/commit 和各业务 owner。只在需要持久化的新游戏事实处增加字段；界面并入行动桌/场景/历史，默认关闭、按题材选择，不强迫日常局启用全部模拟。

## IN-1｜动机竞合：NPC 不再只选第一条可执行任务

**现有边界与需求。** `life.decide` 当前按 crisis、resource、vigilance、trust、prerequisite 顺序返回动作；agency 已接计划和执行回执。玩家希望人物在“有能力做但不愿做”“想做但有更重要承诺”时也有连贯选择，而不是永远执行列表第一项。

**新机制。** 在 life/agency 之前增加有限候选的动机比较：生计、关系承诺、个人追求、恢复需求和风险容忍共同影响选择。动机不是五条固定数值强塞所有人物，题材可声明少量适用维度；人格底色给偏好，近期经历改变当前权重。允许拒绝、协商、替代和延后，保留选择理由与被放弃事项。

**运行闭环。** 读取角色已知事实与可用时间 → 枚举少量合法候选 → 估计该角色眼里的收益/代价 → 选择或提议 → 原 act 执行 → 回执更新目标和承诺。模型可以提出候选，但不能绕过日程、资源、角色自主边界替玩家确认。相同输入可复现，微小波动不会每轮让人物反复改主意。

**差异化体验。** 同样的报酬，守约者可能完成约定，探索者可能接新机会；玩家能通过改善条件而不是操纵隐藏好感数，让对方改变决定。

**玩家验收。** 同一人物面临“赶工挣钱/赴约/休息”，资金短缺、承诺临期、疲劳三组实际状态分别使选择改变；变更承诺有解释和后果。移除某个真实动机输入后，至少一个取舍不同；选择理由不能编造未读到的事实。

**依赖/成本/边界。** A 批，XL；复用 temperament/life/agency/noesis，依赖 OP-2/3 的成本与可行性。不对所有 NPC 每轮调用一个独立模型。

## IN-2｜未走之路的回声：有限预期、遗憾与经验修正

**现有边界与需求。** worldLab 的多轮推演与选择性采纳已经存在，旧头注释比函数导出落后；不可据头注释判断只有静态对比。现阶段缺的是角色如何基于自己的信息形成预期，事后发现判断失误并改变未来选择。

**新机制。** 关键决定保存“当时认为会怎样”，并记录一到两个当时可行但未选的选项。事后将真实已知结果与预期比较，形成有限的遗憾、庆幸或信心修正；反事实只在可比范围估计，不把未发生的支线当成真历史。遗憾既可能促成补救，也可能促成重新解释，不统一自动扣幸福值。

**运行闭环。** IN-1 候选 → 角色局部信息快照和短视距试演 → 选一条实际行动 → 新信息抵达 → 比较预期与结果 → 更新具体情境下的方法偏好/承诺。复用 worldLab/rehearsal 的副本执行能力；先支持已有适配动作，再为确需演算的 OP-2/4 动作补适配。角色模拟不能直接从全知 live store 获取秘密；作者实验室和角色想象分开显示。

**差异化体验。** 同一件事的客观损失相同，曾经选择过与未曾有选择的人反应不同；角色会说得清自己为何改主意，而不是任意情绪重置。

**玩家验收。** 某人曾因误判放弃赴约，后来只在知道错失结果后改变类似决策；从未收到消息的人不产生相同遗憾。不可比的另一条路显示未知，不能算出“本来一定成功”；角色想象不写入地图、库存或别人的记忆。

**依赖/成本/边界。** A 批，XL；依赖 IN-1，复用实验室；每个关键决策有候选数/视距上限，普通日常动作不强制模拟。不是时间倒流或覆盖存档功能。

## IN-3｜共同知晓与默契：知道一件事不等于知道别人也知道

**现有边界与需求。** 一阶知情和传播版本已有，公告投递/已读也已有；这些不等于“甲知道乙收到消息”或“所有参与者都确认约定”。协作剧情需要区分私下通知、公开宣布和共同确认。

**新机制。** 只建有实际需求的两层社会认知：本人相信什么、本人认为指定对方知道什么；配合具名协作事项的确认状态。多人公开见证/共同确认可以形成共享约定，缺席者、迟到者和未读者不自动加入。无需递归生成无限“我知道你知道我知道”。

**运行闭环。** 传讯、对话、公开活动产生可引用见证 → 参与者更新有限社会认知 → 共同计划判断“可配合/需确认/存在误会” → 行动发生或补发询问 → 反馈修正。事实真源继续 intel，社交认知只引用 fact/版本/当事人，不复制世界事实。

**差异化体验。** 谜题与关系冲突可来自合理的协调失败，而非强行降智；玩家能通过召集会议、当面确认、委托传话解决它。

**玩家验收。** 两人分别知道集市改期，却不确定对方知道，于是选择确认而非直接违约；共同确认后能协调出发。通知中断时只有确实收到的人更新，公开更正不穿透封路消息延迟；人物对他人认知的推测允许出错并可被纠正。

**依赖/成本/边界。** B 批，XL；依赖 OP-7，复用 life/liaison/activity/rumor。仅对当前协作所需的参与者建立有限认知关系。

## IN-4｜习俗到制度：世界规则可以被生活塑造

**现有边界与需求。** inst 已有章程、职位、批准、交接，ruling 已有案件过程；目前读到的批准函数主要把提案变为终态。新的价值是让世界中的实践产生可提议的规则，而非只在开局写死章程。

**新机制。** 重复发生的合作、冲突、分配结果可形成“惯例候选”；成员以公开提案、讨论、同意或反对使其成为适用规则。规则有适用范围、受益/承担者、执行成本与复审条件；地方可以共存不同规则，执行效果和不满促成修订。数值支持度不是普遍道德真理。

**运行闭环。** 真实事件/履约结果 → 可说明来源的惯例候选 → 组织内合法提案流程 → 角色表态和所需权限确认 → 新规则由 activity/production/OP-5 实际消费 → 结果反馈后续修订。惯例不自动成为法律，不由统计多数绕过既有批准权限。

**差异化体验。** 同一批角色反复处理工坊排班或公共预算，会长出不同生活方式；玩家可以提出替代安排，而不只接受预设制度。

**玩家验收。** 工坊多次抢工位后提出预约制度，经规定程序通过才改变排班；不通过保留现状。另一组织不受该规则影响，换任负责人也不会自动抹掉旧制度；规则造成新问题时可复审或撤回并处理未完成义务。

**依赖/成本/边界。** B 批，XL；复用 inst/ruling/opinion，依赖 OP-3/5、IN-3。只实现少量具名规则类型，不开放任意字符串执行或万能规则 DSL。

## IN-5｜活的技术谱系：知识会传承、分化，也会失传

**现有边界与需求。** research 已记录项目/成果/范围，training 已记录掌握阶段，但独立成果不等于技术传统。希望技术不仅解锁配方，还受教学、当地材料、设施和实践者影响。

**新机制。** 成果形成具名谱系：前驱方法、改进目标、兼容条件与实践证据。把可读资料与需要指导/练习的默会技巧分开；教学、共同劳动与迁移传播掌握程度。在不同材料/环境下允许经验证的地方变体，有成本/耐用性/适用性取舍，不能无限叠加成全优配方。无活跃实践者时是“暂时无人能做”，不删除文献与历史。

**运行闭环。** OP-4 成果 → 教学/实践 → 地方条件下试用 → 成功或失败证据 → 显式确认变体 → 配方/方法真源增加受支持定义 → 生产和日常行动实际消费。研究失败可以留下错误路径排除证据，不凭空升级。公开文献、组织许可、个人熟练分别表示。

**差异化体验。** 两座城可能都知道一种灌溉或纺织方法，却发展出不同工艺；寻找老师、保留手稿与培养继任者成为实际玩法，而非背景旁白。

**玩家验收。** 同一基础工艺在两地材料条件下得到两种各有取舍的受支持变体；拿到手稿但没受训者不能直接熟练生产。师傅离开后，受训学徒可续作，未完成训练者只能按已掌握范围做；知识恢复不需要把人物秘密记忆复制过去。

**依赖/成本/边界。** A 批，XL；依赖 OP-2/4。首批用纺织、烹饪、灌溉与虚构材料验证机制，参数均为题材声明的游戏抽象。

## IN-6｜公共设施与服务网络：建设改变一地能做的事

**现有边界与需求。** 地点、道路、生产设施、运输和损坏维修已经存在。OP-6 负责现有后果的消费；本项新增“多处设施共同提供服务”的网络机制，而非又做一套维修表。

**新机制。** 设施有可声明服务、供给依赖、容量、覆盖范围与维护责任。例如水渠服务农田、驿站支持行程、公共工坊提供加工能力；网络容量不足会出现排队、降级和可选择的替代服务。玩家可筹资、建设、维护、扩容、改用途，并协商谁付费谁受益。

**运行闭环。** 组织/共同生活提出项目 → 批准预算与劳动 → production/operations 实际施工 → world 中设施提供服务 → 行动与生产消费可用能力 → 维护或需求变化改变服务。线路引用真实地点/连接，不凭空创造道路；产出、消耗、费用继续由原 owner 结算。

**差异化体验。** 一项公共建设能改变多数人的生活路径，利弊分布可见；玩家选择小规模分散建设与集中大设施，体验不同韧性与成本。

**玩家验收。** 建成公共工坊后原本缺设备的成员能预约加工；容量满时等候或改去另一处。停止维护使可用服务逐步受影响，修复依赖 OP-6，不能仅把标签改成“已修复”就产生资源。同一图的分散/集中方案在一次普通故障下有不同可用范围。

**依赖/成本/边界。** B 批，XL；依赖 OP-3/6，复用 operations/org/world。首批选两类服务和小网络，不建设通用网络求解平台。

## IN-7｜有承载力的环境：资源会再生，过度使用会反馈

**现有边界与需求。** weather/region/survival/economy 已提供天候、远方、身体状态与库存；这些不自动构成可再生资源—需求—环境恢复的闭环。新增重点是玩家生产生活会反过来改变所在地的可用条件。

**新机制。** 对题材声明的水、林地、牧场、土壤等抽象资源定义存量、再生条件、使用压力与恢复时滞。开采和生产产生实际需求，休养、修复、替代工艺改变压力；超过承载力影响产能与生活成本。不是每轮随机生成灾难逼玩家干活。

**运行闭环。** 服务/生产/生活需求 → 从已有资源账实际取用 → 记录区域压力 → 按剧情季节和已声明规则恢复 → 下一周期可用量影响路线、工期或替代选择。环境数据是少量区域级状态，不模拟每棵树；交易库存与环境存量有明确提取接口，不能各记一份可无限提取的资源。

**差异化体验。** 短期高产与长期稳定之间有真实取舍；改良技术、共同限额、基础设施可以组合解决问题，而非只有罚款或关机。

**玩家验收。** 持续取水超过补给导致后续可用量下降；采取轮休、节水工艺或调整需求能以不同成本改善。一次“下雨”不自动清除所有累积损耗，物资不凭空再生；关闭环境模拟后仍能按原经济模式游玩。

**依赖/成本/边界。** C 批，XL；依赖 IN-5/6、OP-3。公式和参数属于题材可解释规则，不宣称现实生态预测精度；缺数据不编造科学结论。

## IN-8｜社会遗产：接过的不是记忆，而是一段未完的生活

**现有边界与需求。** family 有财产/照护交接，inst 有职位交接，chronicle/sediment 有历史，motif 只登记意象重复。长线玩法还需要“前人做过的事如何成为后人的处境和选择”，而非简单继承财富与数值。

**新机制。** 由真实已结算事件形成可被看见、传述、承接或拒绝的遗产：未完事业、公共设施、具名物件、师承、被不同群体记住的声誉。继任者可接受目标、重新解释、改用途或放弃；不同见证者可以保留不同版本。纪念活动和地名/物品意义来自历史，不按每轮强制加仪式。

**运行闭环。** 完成事件 → 具有来源的物件/地点/承诺关联 → 显式离任、迁居或剧情交接 → 后继者通过接触/学习获知 → 选择承接范围 → 原 life/gear/operations/family/inst 执行。知识与能力靠传授，秘密靠合法知情路径，生老病死和亲属关系不由计时器强造。

**差异化体验。** 换主角、换任或跨章节仍在同一个世界生活；前代建成的工坊既可能成为事业，也可能成为维护负担或改造机会。

**玩家验收。** 后继者得到工坊使用权但未掌握工艺，需要学习、聘请或转型；前任未完成的公益项目可以明确接手或谢绝。两群人对同一旧事看法不同，不自动合并为官方真相；重载后物件出处、责任与选择仍可追溯。

**依赖/成本/边界。** C 批，XL；依赖 OP-5/8、IN-4/5，复用既有承诺与史料。社会遗产不得覆盖客观事实，不把声誉、技能、情感或记忆当可继承财产。

## IN-9｜历史相变：世界进入新阶段，不能靠把进度条拨回去复原

**现有边界与需求。** era-cycle 的周期阶段与 evolution 的事件推进已有；新机制不再是“每隔若干轮切换时代名”。技术、制度、环境和服务网络同时改变时，世界应当改变可行的生活与组织方式，并保留过程留下的成本。

**新机制。** 用题材声明的少量条件组合描述局部社会状态：例如分散手工、公共协作、服务紧张、恢复转型。状态变化需要持续条件、参与者决定与已兑现设施/技术，而非单一数值阈值。加入进入/退出不同条件与恢复时滞，表示路径依赖；不同地区可以并存不同阶段，信息传播仍有限。

**运行闭环。** IN-4 制度、IN-5 技术、IN-6 服务与 IN-7 环境提供真实读数 → 形成可解释的转型机会/压力 → 玩家与 NPC 采取行动 → 各业务 owner 实际改变成本/方法/协作范围 → 进入新局部状态 → chronicle 记录使变化成立的事件。阶段标签只是结果摘要，不能自己凭空改库存、道路、职位或人物。

**差异化体验。** 同一初始世界因几十轮选择走向不同生活方式；扩张失败再恢复并不等于抹去债务、技能积累和已经形成的习俗。

**玩家验收。** 同一起点分别走公共协作与分散自营，经过实际投资/教学/协商形成不同服务和行动集合；技术公开但缺设施时不能直接跨阶段。短期需求波动不会在两个时代名之间抖动；回退需要明确代价与过渡，不恢复已消耗资源，也不让远方人物全知更新。

**依赖/成本/边界。** C 批，XXL；是前八项联动的旗舰，不是独立大总管。先完成一个题材、两个地区、三种局部状态的纵向玩法，再扩展规则库；不写任意社会演化 AI，不声称能预测现实历史。

## 可执行的大更新编排

采用配套优化计划的 A/B/C 三批，不新增第十九项“总集成平台”。

| 批次 | 本线范围 | 与优化线合并后的完整体验 |
| --- | --- | --- |
| A：人物有取舍，知识能做事 | IN-1、IN-2、IN-5 | 一天的有限时间 → 动机选择 → 研究/教学 → 行动结果 → 经验修正 |
| B：社会会回应，地方会改变 | IN-3、IN-4、IN-6 | 确认约定 → 共同生活/公共规则 → 建设和维护 → 受益与分担 → 新协商 |
| C：世界会积累自己的历史 | IN-7、IN-8、IN-9 | 环境反馈 → 传承或转型 → 局部时代变化 → 历史可解释 → 蓝图重玩 |

每批提供一个跨十余轮的固定可玩场景及至少一条分歧路线；演示中必须使用正常 UI/行动入口，不靠测试直接改底层状态伪造结果。场景初值允许由作者蓝图声明，游玩期间的变化必须由机制产生。各项专项与失败路径随功能交付，真实宿主体验单独确认；不跑未授权全量回归。

### 优先取舍与风险

1. 首先做 A，尽快让人物、时间、方法和研究发生相互作用。IN-9 是依赖最重的旗舰，不能先写一套相变标签然后宣布完成。
2. IN-2 与 IN-3 的认知状态只存关键决策/协作对象，避免每对人物每条事实都生成关系网；IN-7/9 按区域/剧情时段推进。规模约束服务于手机可玩，不发展独立性能治理项目。
3. 只读建议、待确认行动、已提交结果三者在玩家界面明确区分。模型文字负责表达与提案，具体资源/时段/授权由现有机制执行。
4. 建议先用城镇工坊与共同生活作为贯穿题材；以科幻站点复验规则可迁移性，不为第二题材复制整套引擎。
5. 若某新概念只有一段注入文字、一个分数或一张管理表，而不能改变选择和后果，则仍未完成本项。削减界面花活、辅助报表与宽泛规则 DSL，不削减关键玩家路径。
